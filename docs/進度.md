## 延後的決定

- 同步封包改二進位：延後。要做之前先量後期關卡各欄位大小，大頭若是 `e`、`b`、`eb` 只改這三個。量到的（10-17）：第 1 層戰鬥每個封包約 2 KB（最大 3.4 KB）；最壞情況（2 人、難度 20、蟲潮）縮小後每個隊友約 327 KB/s，4 人房主要送 3 份。延後的理由（使用者 10-13）：同步欄位常加，編解碼兩邊沒對齊會靜默錯位、不好除錯。量的方法：chrome-devtools 開兩個分頁（`127.0.0.1:8765` 房主、`localhost:8765` 隊友），包一層 `Net.sendTo` 累計 `t:'s'` 的 JSON 長度。
