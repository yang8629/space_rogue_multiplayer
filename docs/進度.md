## 再下一步：稀有晶片（設計已定，還沒動手）

**規則**
- 稀有晶片 = 玩法晶片＋1 個隨機詞條（詞條 1～3 級）。只出現在玩法晶片。
- 已經有這個晶片也會出現：拿了之後身上那個變稀有，**留在原本的格子、插座上的組件不動（等級跟著組件）**；已有詞條時玩家選「替換」（新詞條從 1 級）或「增強」（原本的 +1 級）；同一個詞條直接增強。
- 出現：一般三選一每格玩法晶片 4%；精英、旗艦的三選一保證一格稀有；旗艦多一次三選一。三選一共用同一個畫面和程式。
- 揭曉動畫：稀有那格先演醞釀、不能按，其他兩格先翻開，最後才翻開稀有。
- 詞條的角色：照這個晶片的玩法打出成果時的獎勵（不是多一種用法、不跟組件重疊）。

| 詞條 | 時機 | Lv1／Lv2／Lv3 |
|---|---|---|
| 餘波 | 發動時（冷卻 0.5 秒） | 在發動位置炸震波：推開敵人＋小傷害，半徑 80／100／120 |
| 淨空 | 發動時（冷卻 0.5 秒） | 清掉發動位置周圍的敵彈，半徑 60／90／120 |
| 迅捷 | 發動時（冷卻 0.5 秒） | 衝刺冷卻 −0.15／0.25／0.35 秒（不能叫疾風：跟加速器 2 層撞名） |
| 狂熱 | 玩法擊殺 | 3 秒內射速 +6／9／12%，最多 5 層 |
| 爆發 | 充能 | 充滿朝四周 8 個方向開槍（整條電路）；正常使用約 10／8／6 秒充滿 |
| 反擊 | 受傷時（冷卻 2 秒） | 這個晶片強制發動一次（每個晶片各寫，放在 `CHIPS` 表） |
| 結晶 | 玩法擊殺 | 每 10／8／6 次得 1 層護盾（最多 1 層） |
| 收割 | 玩法擊殺 | 回 0.5／0.75／1 HP（每秒最多 3） |

**實作計畫**
- id：`base~插座` 後面加 `!詞條等級`（例 `boomerang~3!aftershock2`；組件升級之後 id 不再有 `#等級`）。`chipId` 多一個參數；保留詞條的地方：`fullChip`、editor.js 拖放、`parseChipId` 的正規式（多人同步也靠它）。
- 詞條表放資料檔，數值和行為都在表裡（程式碼規則 1）。
- 發動點：`Game.rareAct(base, x, y, owner)`，只在房主跑，owner = 那個人的配裝 L（房主自己 null）。
  - 迴旋：entities.js `mode = 'return'`；環繞：`orbShot = true`；佈雷：`dashed = true`；加速：`accelMul` 越過 2；牆反彈：`bounced = true`（entities.js 兩處、objects.js 一處）。
  - 反向：有 `b.rear` 的子彈射出；蓄力：chips.js `full`；衝刺射擊：entities.js `fireMode = 'dashfire'`；架設：`standFull` 變 true。
  - 黏著：game.js `detonate`；感染：`infectBurst`；吸引：game.js 拉人的兩處；攔截：`interceptHit`。
  - 玩法擊殺：`payGrowTags` 裡的每個 `q.id`；受傷：`hurtPlayer`。
- 爆發的充能：先用 `tests/probe.js` 量每個晶片每分鐘發動幾次，再把「每次充多少」寫進表。
- 三選一：`CFG.REWARDS` 加 `rare`（保證幾格稀有：elite 1、boss 1）、`after`（旗艦拿完回到勝利畫面）；旗艦 = `combatWon` 先 `openReward('boss')` 再進勝利畫面。替換／增強：卡片上兩個按鈕。揭曉：`R.revealed` 記住（重繪不重播，刷新才重播）。
- 還要：卡片和電路格的金框、模擬電腦（稀有分數加成、預設增強）、機制檢查（每個詞條、id、繼承、替換／增強、保證稀有）、總覽規則頁、README、截圖。

## 怎麼測（瀏覽器）

- 起本機伺服器：在專案上一層 `python3 -m http.server 8765 --bind 127.0.0.1`，開 `http://127.0.0.1:8765/<資料夾>/index.html`；console 跑 `MechCheck.runAll()`。
- 多人：每個玩家用不同網址開（`127.0.0.1:8765`、`localhost:8765`…，存檔才分開）；房主 `Net.lobby(); Net.host()`，隊友 `Net.lobby(); Net.join('房號')`。
