# 局外成長草稿（解鎖型）

2026-10-18 草稿。使用者選了「先做局外成長，再定章節數值」，方向是解鎖型；接著說「先做相關的畫面，但先維持全解鎖」。

**已做（10-18）**：`js/data/unlocks.js`（條件、跨局進度、`isUnlocked`）、`CFG.UNLOCK_ALL = true`（全開）、一局結束加進度（`Game.saveRecord`；精英、回響擊殺在多人時跟著傷害統計同步）、畫面（標題「🔓 解鎖」、解鎖一覽、選飛船／選武器的鎖住卡片、結算和標題的「達成解鎖條件」）、機制檢查「解鎖進度」。
**已做（10-18，下一版）**：使用者同意這份草稿＋攔截改跟相位刃一起開；`CFG.UNLOCK_ALL = false`、晶片池過濾（`openChips`）、存檔升級（`unlockUpgrade`）、`--locked` 模擬。
**還沒做**：跑 `--locked` 模擬，看雷射少了收束會不會掉很多（掉很多就把收束改成開局就有）；匯出／匯入代碼。

## 原則

- 解鎖只增加**選項**（新飛船、新武器、新晶片），不加數值：玩越多選擇越多，但不會越來越強。
- 條件都是正常玩就會達成的事，不用刷；目標約 15～25 局全部解鎖（數字之後用模擬調）。
- 沙盒、靶場一律全開（測試、練習用）。
- 整局模擬預設全開（測的是解鎖完的遊戲）；另外加 `--locked` 模擬新玩家的池子。

## 解鎖條件

**飛船、武器：照打到哪裡**

| 解鎖 | 條件 |
|---|---|
| 幻影號 | 打倒星噬母艦（第 1 星區旗艦）一次 |
| 軌道砲 | 到達第 2 星區 |
| 星門號 | 打倒裂界獵艦（第 2 星區旗艦）一次 |
| 相位刃 | 到達第 3 星區 |
| 哨兵號 | 通關第一章 |

**玩法晶片：用相關的晶片打出「玩法擊殺」**（玩法擊殺＝那個晶片的效果打死敵人，遊戲已經在記，紀錄畫面看得到）

| 解鎖 | 條件（累計，跨局） | 為什麼是這個 |
|---|---|---|
| 牆反彈 | 迴旋 100 次 | 都是讓子彈「回來」再打一次 |
| 攔截 | 到達第 3 星區（跟相位刃一起） | 相位刃要裝攔截才會格擋，先拿到刀卻沒有攔截就少了主要的搭配 |
| 吸引 | 佈雷 100 次 | 吸引把敵人拉進地雷堆 |
| 加速 | 蓄力 100 次 | 都是「等一下換更痛」 |
| 感染 | 黏著 100 次 | 都是打在身上再擴散 |

**組件、觸發器：照累計的事**

| 解鎖 | 條件（累計，跨局） |
|---|---|
| 鏡像迴路 | 完成 3 局（輸贏都算） |
| 超頻模組 | 架設 玩法擊殺 100 次 |
| 破甲彈頭 | 打倒 10 隻精英 |
| 收束透鏡 | 用軌道砲或雷射打倒任一旗艦 |
| 電擊線圈 | 累計擊殺 2000 隻敵人 |
| 消失觸發器 | 回響（觸發器射出的子彈）累計擊殺 300 隻 |
| 定時觸發器 | 回響累計擊殺 1000 隻 |

## 畫面

- 標題畫面多一個「🔓 解鎖」：列出全部東西，沒解鎖的灰色，寫條件和進度（例：迴旋 玩法擊殺 63/100）。
- 選飛船、選武器：沒解鎖的卡片照樣顯示、灰掉、寫條件（讓玩家知道還有東西可以拿）。
- 三選一、商店、黑市、開局晶片：只出現解鎖了的晶片。
- 一局結束（結算畫面）：有新解鎖就列出來「🔓 新解鎖：幻影號」。

## 多人

- 飛船、武器：各自從自己的解鎖裡選。
- 三選一、商店本來就各自選：照自己的池子。
- 進度：打倒旗艦、到達星區、通關 → 一起打的每個人都算；玩法擊殺、擊殺數照各自的。
- 章節：照現在的規則（所有人都解鎖才能選）。

## 存檔

- 存在瀏覽器（跟章節進度一樣，`localStorage`），換瀏覽器或清除網站資料會不見；之後可以加「匯出／匯入」的代碼。
- 進度從 2.20.0 開始算（使用者 10-18）：2.20.0 以前的遊玩紀錄刪掉、章節進度重來（只照 2.20.0 以後通關的紀錄）。以後加新條件 → 用遊玩紀錄補新成績（`UNLOCK_STATS`、紀錄的 `ulk`）。

## 對平衡、模擬的影響

- 不加數值 → 章節難度照現在的強度定，模擬的數字還能用。
- 新玩家的池子比較小，組合少：前幾局的難度要用 `--locked` 模擬看一次（可能比較難，也可能因為選項少、比較容易湊出配裝而比較簡單）。

## 程式（做的時候）

- 新資料表 `js/data/unlocks.js`：每項 `{ 種類, id, 條件說明, 進度函式 }`，流程只查表（程式碼規則 1）。
- 進度事件：打倒旗艦、到達星區、通關、結算（擊殺數、玩法擊殺、回響擊殺）。
- 過濾的地方：選飛船、選武器、開局晶片、三選一（`openReward`）、商店、黑市、？事件給的晶片。
- 機制檢查：鎖住的不會出現在獎勵池；條件達成會解鎖；沙盒全開；多人各自的池子。
