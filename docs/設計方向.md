# 設計方向

> 改玩法、設計新東西（晶片、武器、飛船、敵人、章節、數值）前必讀。表格和「定義」的內容由使用者決定，AI 不自己改；寫「未定」的項目，遇到時先問使用者。

| 項目 | 方向 |
|---|---|
| 一句話介紹 | 開著能改裝的飛船一路打進星環，每局用電路、晶片、零件長出不同流派的太空射擊 roguelite |
| 最終目標 | 上架販售的完整遊戲。網頁版當原型，內容和平衡在這裡做完，再移植到 Godot |
| 上架形式 | 未定（搶先體驗或完整版） |
| 參考作品 | 未定 |
| 玩法重心 | 單人為主：數值和新設計以單人為準。多人（2～4 人）保留，只套人數倍率；新機制照樣要做多人同步 |
| 內容量 | 繼續加（章節、王、武器、飛船、晶片）；第一個完整版要多少未定 |
| 一局時間 | 未定 |
| 戰鬥重點 | 組合爆發、閃避走位、割草清怪、打王，四個都要，不為了其中一個犧牲另一個 |
| 難度 | 熟練玩家每把武器各自約 20% 通關（看每把，不看平均） |
| 成長方式 | 局內：組件插在玩法晶片上升級（插 2 個進化）、稀有晶片詞條、零件疊層開特性、武器升級樹。局外：解鎖只加選項（飛船、武器、晶片），不加數值 |
| 爽感 | 組合疊起來爆發、成群敵人被一口氣掃光；隨機的驚喜（稀有晶片、寶藏無人機、蟲潮、精英亂入） |
| 重玩動機 | 每局組出不同打法（飛船 × 武器 × 晶片）、追求爽感；解鎖讓選項越玩越多 |
| 不想要的東西 | 只加數值的晶片；逼玩家打快的時間壓力（增援、狂暴計時）；限制疊加的上限；為了通用構築加新系統；手機版 |

## 定義

每樣東西是什麼、要做到什麼。新增或修改時照這裡；跟這裡不合的先問使用者。

- **武器**：決定基本手感（射法、射速、射程），固定在電路第 1 格；升級樹的終極升級＝一種打法，效果來自武器本身。
- **玩法晶片**：改變子彈或打法的行為（迴旋、環繞、佈雷…），不加數值。
- **組件**：數值放這裡（分裂、穿甲、超頻…）；插在晶片的插座上，讓玩法晶片升級（插 2 個進化）。
- **稀有晶片**：玩法晶片＋1 個詞條（什麼時候觸發、做什麼）。
- **觸發器**：在某個時機用武器多射一次回響；右邊的晶片只作用在回響上。
- **飛船**：開局配置＋一個專屬能力；能力要改變打法（例如殘影引走敵人、衝刺留砲台），不是數值。
- **零件**：局內的數值成長；每層小好處＋小代價，同種疊 2、4 層開特性。
- **組合**：武器特性改變晶片行為、晶片之間互相影響，組出意外的效果；這是遊戲的核心樂趣。
- **疊加**：同一種效果可以一直疊，不設上限；太強就放慢成長。
- **疊法**：同一項屬性「增加」相加、「減少」相乘；武器層的倍率（升級、超頻）相乘。
- **獎勵**：讓戰力變強（傷害、生存），不只是變快。
- **節奏**：慢慢打也能過，沒有時間壓力。
- **美術**：共通畫法是切面上色、`#03050c` 描邊、左上光、發光的地方用加法發光＋bloom、圖集貼圖；不要虛線、太細的突出。基地和飛船用金屬藍灰。戰場的牆照星區換風格（金屬、岩石 → 冰、廢墟 → 熔岩、生物巢穴），越深入越陌生。怪物見「怪物」那條。
- **怪物**：同一個機械蟲族，等級越高越機械化：小怪偏生物（甲殼、肉質），精英一半機械，王幾乎是機械戰艦但留蟲的特徵；共通畫法（切面、深色描邊、左上光、發光），每種一個代表色。
- **平台**：電腦版。
