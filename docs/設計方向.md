# 設計方向

> 改玩法、設計新東西（晶片、武器、飛船、敵人、章節、數值）前必讀。表格的內容由使用者決定，AI 不自己改；寫「未定」的項目，遇到時先問使用者。

| 項目 | 方向 |
|---|---|
| 一句話介紹 | 開著能改裝的飛船一路打進星環，每局用電路、晶片、零件長出不同流派的太空射擊 roguelite |
| 最終目標 | 上架販售的完整遊戲。網頁版當原型，內容和平衡在這裡做完，再移植到 Godot |
| 上架形式 | 未定（搶先體驗或完整版；現在不是重點） |
| 參考作品 | 未定 |
| 玩法重心 | 單人為主：數值和新設計以單人為準。多人（2～4 人）保留，只套人數倍率；新機制照樣要做多人同步 |
| 內容量 | 繼續加（章節、王、武器、飛船、晶片）；第一個完整版要多少未定 |
| 一局時間 | 未定。現在（2026-10-20 量）：見下方「現況」 |
| 戰鬥重點 | 組合爆發、閃避走位、割草清怪、打王，四個都要 |
| 難度 | 熟練玩家每把武器各自約 20% 通關（看每把，不看平均）；現在不是重點 |
| 成長方式 | 局內：組件插在玩法晶片上升級（插 2 個進化）、稀有晶片詞條、零件疊層開特性、武器升級樹。局外：解鎖只加選項（飛船、武器、晶片），不加數值 |
| 重玩動機 | 飛船 × 武器 × 晶片組合出不同打法；解鎖讓選項越玩越多 |
| 不想要的東西 | 只加數值的晶片；逼玩家打快的時間壓力（增援、狂暴計時）；限制疊加的上限；為了通用構築加新系統；手機版 |

## 調整時的判斷依據

- **晶片**：要改變玩法，不是加數值；數值成長走別的管道（組件、零件）。
- **組合**：使用者喜歡組合出意外效果（武器特性改變晶片行為）；獎勵要是傷害、戰力，不只是速度。
- **疊加**：不限制環繞、黏著這類疊加（那是樂趣）；太強就放慢成長，不加上限。
- **疊法**：同一項屬性「增加」相加、「減少」相乘；武器層的倍率（升級、超頻）相乘。
- **武器終極升級**：每個是一種打法，效果來自武器本身；先查跟現有晶片、組件有沒有重疊；快速射擊的武器不做連鎖滾雪球。
- **飛船專屬能力**：要改變打法；只是衝刺變遠、冷卻變短被否決過（使用者 10-18：「沒特別的」，哨兵號改成砲台）。
- **戰鬥重點**：四個重點不能為了其中一個犧牲另一個。例如加強割草感時，不能讓走位變得不重要。
- **節奏**：慢慢打也要能過，不用時間壓力、越拖越強逼玩家打快。
- **多人**：數值照單人量；多人只看會不會壞（同步、卡頓、斷線）。
- **美術**：切面上色、`#03050c` 描邊、左上光、金屬藍灰漸層、加法發光＋bloom、圖集貼圖；不要虛線、太細的突出。
- **平台**：電腦版，不為手機規劃效能或替代方案。

## 現況

- 內容：3 章、5 把武器、5 艘飛船、13 個玩法晶片、5 種零件。
- 一局時間（2026-10-20 整局模擬，第一章，每把武器 20 局，通關的 22 局）：只算戰鬥平均 18 分鐘（最快 11、最慢 29；電漿最久平均 27），每星區約 4／6／9 分鐘，越後面越久。真人還要加上航圖、三選一、商店的時間，打得也比模擬電腦慢。
