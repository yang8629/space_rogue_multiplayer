# 設計方向

> 改玩法、設計新東西（晶片、武器、飛船、敵人、章節、數值）前必讀。表格和「定義」的內容由使用者決定，AI 不自己改；寫「未定」的項目，遇到時先問使用者。

| 項目 | 方向 |
|---|---|
| 一句話介紹 | 開著能改裝的飛船一路打進星環，每局用電路、晶片、零件長出不同流派的太空射擊 roguelite |
| 最終目標 | 上架販售的完整遊戲。網頁版當原型，內容和平衡在這裡做完，再移植到 Godot |
| 上架形式 | 未定（搶先體驗或完整版） |
| 參考作品 | 未定 |
| 玩法重心 | 單人為主：數值和新設計以單人為準。多人（2～4 人）保留，只套人數倍率；新機制照樣要做多人同步 |
| 內容量 | 繼續加（章節、王、武器、飛船、晶片）；第一個完整版要多少未定 |
| 一局時間 | 未定 |
| 戰鬥重點 | 組合爆發、閃避走位、割草清怪、打王，四個都要，不為了其中一個犧牲另一個 |
| 難度 | 熟練玩家每把武器各自約 20% 通關（看每把，不看平均） |
| 成長方式 | 局內：同種晶片合成升級（3 片 Lv3）、稀有晶片詞條、零件疊層開特性、武器升級樹。局外：解鎖只加選項（飛船、武器、晶片），不加數值 |
| 爽感 | 組合疊起來爆發、成群敵人被一口氣掃光；隨機的驚喜（稀有晶片、寶藏無人機、蟲潮、精英亂入） |
| 重玩動機 | 每局組出不同打法（飛船 × 武器 × 晶片）、追求爽感；解鎖讓選項越玩越多 |
| 不想要的東西 | 只加數值的晶片；逼玩家打快的時間壓力（增援、狂暴計時）；限制疊加的上限；為了通用構築加新系統；手機版 |

## 定義

每樣東西是什麼、要做到什麼。新增或修改時照這裡；跟這裡不合的先問使用者。

- **故事**：星環是圍著一顆恆星的古老環狀能量電路，分成一段段星區；機械蟲族從星環深處湧出、啃食電路，把吞下的零件長在自己身上（所以越高級越機械，王是被蟲族改造過的星環設施或戰艦）。越深處侵蝕越嚴重（牆從金屬、岩石變成冰、廢墟、熔岩、生物巢穴）。玩家是駕駛員：每局＝一次出擊，往深處推進、從擊落的蟲族身上回收電路（＝晶片）接到自己的飛船上；通關＝打穿這一章的星區、擊沉盤據的王；陣亡＝飛船被擊毀、駕駛艙彈射回站，戰績和解鎖留下。
- **基地**：星環外緣最後一座還在運作的中繼站，駕駛員出擊的據點（多人房間＝大家在同一座站）。中央大廳是控制中心，正中的能量核心是站接上星環取電的地方，能量導管送到發射台；其他房間都是站的設施：機庫停放能開的飛船、軍械庫放武器（含靶場）、晶片實驗室研究回收的電路、戰績室記錄擊沉的王、觀景台看得到星環、發射甲板是出擊口。玩家就是飛船：站裡沒有給人用的東西（椅子、盆栽）。
- **飛船晶片**：電路第 1 格，固定不能拔，是線頭；插在它上面的插件作用在飛船的所有攻擊（左鍵、右鍵、武器升級、衝刺撞擊、砲台），也往下傳給整條線。
- **武器**：決定攻擊的動作（怎麼出手、軌跡、右鍵技能）和基本數值；升級樹的終極升級＝一種打法，效果來自武器本身。
- **線**：電路只有一條線：飛船晶片＋後面的晶片。觸發器（衝刺、定時）拿掉了，之後可以做成飛船或武器升級。
- **晶片**：在線上放出自己的產物（迴旋刃、地雷、孢子…），**不改武器的攻擊**；產物的動法由晶片自己決定（想要不同的動法就做新晶片，不做「改別人產物」的修飾型）。同一條線上，前一格的產物觸發下一格：每片晶片固定一種「往下傳的條件」（命中、爆炸、擊殺）和係數。每往下一層傷害打折。連鎖可以越往下越爆，這是爽感來源。「再打一次武器」是一片晶片（回響）。
- **觸發公平**：武器命中照觸發係數累積（命中頻率不同的武器觸發次數差不多）；每把武器的招牌動作每次直接觸發 1 次（光束排熱、飛輪召回、重力井塌縮、鉤爪甩擊、能量刃重斬、蜂群收攏），不設上限、次數由武器自己的規則限制；產物強度固定，不照觸發那一下的傷害算。
- **插件**：插在晶片（含武器）的插座上，**會傳給同一條線上它後面的所有晶片，同種加總**（插越前面影響越多片）。只有：物理傷害、大小、元素（燃燒、冰凍、電擊、破甲、爆裂）。**不做增量的插件**（數量、頻率）：數量只靠晶片的觸發來長。插件不影響晶片等級。
- **傷害分兩種**：物理 = 產物本身打中的那一下（吃傷害插件、晶片等級）；屬性 = 元素造成的（電弧、燃燒…），強度靠疊同種元素（例：3 個電擊 = 電 3 隻、電弧更痛），不吃傷害插件、晶片等級。
- **數量控制**（多人也要撐得住）：唯一的增量來源是晶片觸發；每個玩家一份產物預算，超過的不再多放、改成讓這一批變大變痛；每幀觸發有上限。平衡要用「插座全塞滿」的最壞配裝測過，不靠稀有度。
- **晶片升級（自選合成）**：把晶片拖到同種晶片上＝合成，等級相加（2 片 Lv2、3 片 Lv3）；不合成就分開放，同一種可以放好幾片。合成省格子、Lv2 傷害 ×1.5、Lv3 傷害 ×2.5（先只加數值，進化之後再做）；分開放產物和觸發點多一份。合成不能拆回來。卡片上顯示收集進度（例：碎片 2/3）。Lv3 進化的內容、被合成掉那片身上的插件去哪：未定。
- **稀有晶片**：每片晶片有自己的稀有版（不做通用詞條：通用的會在某些晶片上沒效果或很怪）；稀有版照那片晶片的特色換往下傳的條件或觸發位置，不加產物數量。一般晶片的條件固定，不隨機。每片的稀有版：感染＝第二代孢子打死也往下傳；迴旋＝只有回程打中才傳、每次 1；佈雷＝沒被觸發消失時自爆並往下傳；碎片＝也打得到觸發的那隻、6 片打中同一隻多傳 1 次；追蹤彈＝打中後彈去下一隻、第二下也傳；漩渦＝吸到 5 隻以上結束時傳 2 次；回響＝從飛船朝準星打。取得：三選一小機率、精英／寶藏保證一張、商店（較貴）。
- **飛船**：開局配置＋一個專屬能力；能力要改變打法（例如殘影引走敵人、衝刺留砲台），不是數值。
- **零件**：局內的數值成長；每層小好處＋小代價，同種疊 2、4 層開特性。
- **組合**：武器特性改變晶片行為、晶片之間互相影響，組出意外的效果；這是遊戲的核心樂趣。
- **疊加**：同一種效果可以一直疊，不設上限；太強就放慢成長。
- **疊法**：同一項屬性「增加」相加、「減少」相乘；武器層的倍率（升級、超頻）相乘。
- **獎勵**：讓戰力變強（傷害、生存），不只是變快。
- **節奏**：慢慢打也能過，沒有時間壓力。
- **美術**：共通畫法是切面上色、`#03050c` 描邊、左上光、發光的地方用加法發光＋bloom、圖集貼圖；不要虛線、太細的突出。基地和飛船用金屬藍灰。戰場的牆照星區換風格（金屬、岩石 → 冰、廢墟 → 熔岩、生物巢穴），越深入越陌生。怪物見「怪物」那條。
- **怪物**：同一個機械蟲族，等級越高越機械化：小怪偏生物（甲殼、肉質），精英一半機械，王幾乎是機械戰艦但留蟲的特徵；共通畫法（切面、深色描邊、左上光、發光），每種一個代表色。
- **平台**：電腦版。
