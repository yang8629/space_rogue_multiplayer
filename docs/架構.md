# 架構

> 改程式前讀對應的段落。新增、拆分、搬移檔案，或改了某個檔案負責的事，同一個提交裡改這份。程式碼規則在 `CLAUDE.md`。

## 為什麼這樣分

網頁版是原型，內容和平衡做完後移植到 Godot（見 `設計方向.md`）。所以：

- **邏輯和畫面分開**：遊戲邏輯只改狀態、發事件；畫面只讀狀態、聽事件。移植時只重寫畫面層。
- **資料是純表**：數值和定義放 `js/data/`，移植時轉成 Godot 的 Resource／JSON。
- **事件取代直接呼叫**：`Events.emit` 對應 Godot 的 signal。
- **效能**：畫面、每幀的程式不重複線性搜尋、不重算；改完量頁面（超過 100 ms 要修）。上限、門檻照實測定，量的結果寫在設定旁邊。

## 分層

```
js/data/    資料表：數值、定義（武器、晶片、零件、飛船、章節、詞綴、事件、航圖產生）
js/core/    共用：設定 CFG、小工具、事件、空間格子、子彈格式、電路執行、主迴圈
js/game/    遊戲邏輯：一局的流程、戰鬥、實體、場地、地圖物件、基地、靶場
js/system/  跟外界接：輸入、音效、設定、多人連線
js/ui/      畫面：WebGL 世界（gl/）、2D 畫布的 HUD、DOM 介面（選單、面板、編輯器）
```

| 層 | 可以用 | 不可以 |
|---|---|---|
| data | core 的小工具；表裡的函式（`CHIPS[id].apply`）在遊戲中才執行，可以用 game | 存檔以外的副作用 |
| core | data | game、ui（`main.js` 例外：它負責接起所有東西） |
| game | data、core、`Events`、`Net`（多人同步）、`Input` | DOM、`GLR`／`GL*`、`Screen`、`FX`、`SFX`（要表現就 `Events.emit`） |
| system | data、core、game | 畫面（`net.js` 現在違反，見重整清單） |
| ui | 全部都能讀；改遊戲只能呼叫 `Game`／`Hub` 的方法（按鈕 → `Game.buy(i)`） | 直接改遊戲欄位；每幀重複線性搜尋 |

載入順序只寫在 `index.html`。所有檔案共用同一個全域範圍，function 宣告只在自己的檔案內提前：載入時就執行的程式碼不能呼叫後面檔案的函式。

## 一幀（`core/main.js` 的 `frame`）

`Net.tick`（收送多人訊息）→ `Game.update`（戰鬥）→ `Hub.update`（基地）→ `Range.tick`（靶場）→ `render()`（WebGL 世界 `GLR`＋2D 畫布的 HUD）。每幀最多 1/30 秒；模擬（`tests/`）用固定 1/60 秒直接呼叫 `Game.update`，不經過 `frame`。

## 遊戲狀態（`Game.state`）

| 狀態 | 是什麼 | 畫面（`ui/listeners.js` 的 `VIEWS`） |
|---|---|---|
| `title` | 基地（單人） | `Screen.title` |
| `lobby`、`pick` | 多人：大廳、房間裡的基地 | `Net.renderLobby`、`Screen.hubPick` |
| `map` | 航圖 | `Screen.map` |
| `play` | 戰鬥（也是靶場） | 沒有 DOM；Esc 選單 `Screen.pauseMenu` |
| `reward`、`shop`、`workshop`、`armory`、`event`、`blackhole` | 三選一、補給站、改裝廠、軍械台、？事件、奇異點 | 同名的 `Screen.*` |
| `editor` | 電路編輯器（Tab）；關掉回到 `returnState` | `Editor` |
| `victory`、`dead`、`ended` | 打倒旗艦、陣亡、這一局結束 | 同名的 `Screen.*` |

換狀態後呼叫 `Game.view()`，它發 `view` 事件，`listeners.js` 照狀態畫對應的頁。

## 一局的流程

`Game.newRun` → `showMap`（航圖）→ `enterNode`（照節點種類進戰鬥或各種站）→ `startCombat` → `startWave`／`updateWaves` → `combatWon` → `openReward`（三選一）→ 回航圖 → 第 7 層旗艦 → `nextSector` → 最後一個星區打完 `finishRun` → `saveRecord`（遊玩紀錄＋解鎖進度）。

## 事件（`Events`）

邏輯發、`ui/` 聽。完整清單用 `grep "Events.emit('"`。

| 類別 | 事件 | 誰聽 |
|---|---|---|
| 換頁 | `view`、`editor`、`editorMsg` | `listeners.js` |
| 特效 | `burst`、`trail`、`floatText`、`ring`、`zap`、`flash`、`banner`、`shake`、`fxClear`、`fxTick` | `ui/fx.js`（發的一方用 `game/effects.js` 的小函式） |
| 音效 | `shoot`、`hit`、`dash`、`enemyShot`、`enemyKilled`、`playerHurt`、`explode`、`waveStart`、`bossArrive`… | `listeners.js` 的音效表 |
| 基地 | `hubNear`、`hubSwap`、`hubLaunch`、`hubFire`、`hubDash` | `listeners.js`、`net.js` |

## 存檔（瀏覽器 localStorage）

| 名稱 | 內容 | 在哪 |
|---|---|---|
| `v2_runRecords` | 遊玩紀錄 | `config.js` 的 `RECORDS_KEY`，`Game.saveRecord` 寫 |
| `v2_chapters` | 通關的章節 | `chapters.js` |
| `v2_unlocks`、`v2_unlock_seen` | 解鎖進度、看過的「新」 | `unlocks.js` |
| `v2_lastPick` | 上次的飛船和武器 | `hub.js` |
| `v2_settings`、`muted`、`music`、`autoFire` | 設定 | `settings.js`、`audio.js`、`input.js` |
| `v2_seat`（sessionStorage） | 多人重新整理後回到同一個位置 | `net.js` |

## 多人

- **連線**：WebRTC 點對點（PeerJS 1.5.4）。PeerJS 的公開伺服器只負責配對；房號對應 Peer ID `circuitrogue-mp-XXXX`。沒有中繼伺服器（TURN），少數網路打不通。
- **房主算整個戰場**：敵人、所有子彈、傷害、掉落、地圖物件、傳送門；替隊友開火（`Game.withLoadout` 暫時換上隊友的配裝）。每秒 30 次送戰場快照。
- **隊友算自己的移動和衝刺**（零延遲），每秒 30 次送位置和「有沒有按開火」；商店、獎勵等節點在自己電腦上處理，回航圖時把配裝傳給房主。
- **隊友畫面上的敵人、子彈是同步來的資料**：畫面和兩邊共用的程式只讀欄位，不呼叫方法。
- **基地（房間）是輕量同步**：只傳位置、開火、衝刺，各自畫、各自算，互射只推開不扣血。
- **對方的資料一律不可信**：晶片 id、武器、零件層數、星圖、數值範圍都先檢查。
- 一則訊息超過 16KB（PeerJS 上限）會切段送；5 秒沒收到任何訊息算斷線（切到背景放寬到 70 秒）。
- 訊息種類：看 `net.js` 的 `onData` 裡的 `case`。

## 重整清單

照順序做；做完一項就從這裡刪掉，寫進 `版本紀錄.md`。

1. **基地換成戰鬥飛船**：基地用 `Player`、`Bullet`、`Dash`、飛船能力，`hub.js` 自己的射擊（`updateShots`、`addFire`）、子彈、衝刺特效（`dashFx`、`puff`、`hop`）全部拿掉，只留配置和互動。基地 = 沒有敵人的戰鬥場地。
2. **拆 `game.js`**：照責任拆成幾個檔，都往同一個 `Game` 加方法（`Object.assign(Game, {...})`，跟 `base.js` 往 `Screen` 加一樣），外面呼叫的名字不變：流程與紀錄、波次與敵人生成、晶片效果與稀有詞條、機體與飛船能力、獎勵與各種站。
3. **拆 `entities.js`**：`ENEMY_TYPES` 搬到 `js/data/enemies.js`；敵人 AI（`THEME_AI`、`ELITE_AI`、`BOSS_MOVE`、王的招式）搬到 `js/game/enemy_ai.js`。
4. **`net.js` 不碰畫面**：大廳 HTML、等待畫面、倒數文字搬到 `js/ui/lobby.js`；`net.js` 改成發事件。
5. **`range.js` 不碰 DOM**：靶場按鈕列搬到 `ui/`。
6. **存檔集中**：所有 localStorage 讀寫搬到 `js/system/save.js`（一個地方管名稱、格式、存檔升級），之後換成 Godot／Steam 的存檔只改這一檔。
