# 星環電路 Circuit Rogue：雙人連線版 V2（實驗）

## V2 有什麼不同

V1 的晶片大多只是數值加成，構築到最後都是「把數字疊高」。V2 把重點改成**改變玩法**：

| 系統 | V2 |
|---|---|
| 晶片 | 13 個改變玩法的晶片（迴旋、環繞、佈雷……），**越用越強**，Lv3 進化；數值晶片改成**組件**，插在晶片的**插座**上；3 種觸發器 |
| 機體 | 飛船改成「開局配置」，之後靠**零件**（5 種，疊層數開特性）和**背包模組**（1 格）長出流派 |
| 飛船 | 新飛船**星門號**：衝刺開一對傳送門 |
| 航圖 | 新節點**改裝廠**（零件）；精英改給背包模組；旗艦多給零件格和專屬模組 |
| 戰場 | **地圖物件**：行星、黑洞、彗星、小行星帶 |

V1 和 V2 的遊玩紀錄分開存，不會互相覆蓋。

## 晶片

電路由左至右執行，第 1 格固定是武器。玩法晶片作用在它左邊已經產生的子彈（貼在子彈上的特性，分裂複製子彈時會一起複製）。**組件**（分裂、巨彈、穿甲、倍增、超頻、鏡像、爆裂、燃燒、冰凍、電擊）插進武器、玩法晶片或觸發器的**插座**（晶片卡下面的圓，不佔電路格），見下面「插座與組件」。**觸發器**右邊的晶片只作用在觸發後射出的回響上。

### 改變玩法的晶片（照著玩法打就會成長）

| 類型 | 晶片 | Lv1 | Lv3 進化 |
|---|---|---|---|
| 彈道 | **迴旋** | 一定會飛回來：打中敵人（有穿甲時穿甲用完）就穿過去再折返，回程再打牠一次；撞到牆（方形場地的邊緣）、行星、小行星，或飛到射程盡頭也折返。回程追著射出它的飛船、一路無限穿透（傷害 ×0.7）。相刃（無限穿透）：刃片揮到盡頭就飛回來 | 迴旋風暴：折返時分裂成 3 發 |
| 彈道 | **環繞** | 按住射擊時子彈存在飛船旁繞圈（Lv1 最多 10 發、Lv2 20 發，一次開火算一發（散彈一次的 5 顆算一發），碰到敵人照打；同一隻隔 0.5 秒可再打，每打一次扣一次穿甲，用完消失），越繞越快；放開射擊時全部從所在位置朝滑鼠那一點射出（衝刺不會放出；存滿後按住不再射），轉越快放出越快：Lv1 3 秒轉滿（速度與傷害 ×1.5），Lv2 2 秒轉滿（×2）。觸發射出的子彈不進圈。搭加速：從放出時的倍率繼續加上去（不相乘） | 星環：射出的子彈追蹤敵人 |
| 彈道 | **佈雷** | 子彈飛到射程一半時停住變成地雷（4 秒，Lv2 6 秒）：敵人的邊緣進到 50（Lv2 70）內就用武器原本的速度朝牠衝出去，跑完剩下的射程（至少比觸發範圍遠 30），加速、疾射接著停住前的進度算（大隻的敵人在旁邊也會觸發），傷害 ×1.2；時間到沒被觸發就消失。不擋子彈。搭迴旋：衝出去打中後折返，用武器原本的速度飛回 | 伏擊網：每顆地雷和最近的 2 顆（110 以內）之間拉出電弧 |
| 彈道 | **加速** | 子彈出手只有 0.5 倍速，越飛越快，射程 ×1.5。速度照「飛了射程的幾成」算：出手 0.5 倍，射程盡頭 3 倍（Lv2 4 倍），每把武器都一樣（遠近照各自的射程換算）；速度倍率加進傷害加成，近距離虧、遠距離痛。搭環繞：從放出時的倍率繼續加；搭佈雷、迴旋：衝出去、回程接著原本的進度算 | 超音速：2 倍速以上無限穿透 |
| 彈道 | **疾射** | 跟加速相反：出手 3 倍（Lv2 4 倍），照「飛了射程的幾成」變慢，射程盡頭 0.5 倍；射程不變。近距離很痛、遠距離變弱。跟加速、環繞放出加在同一個倍率上（疾射＋加速同等級 = 整段固定倍率） | 衝擊：2 倍速以上打中時強力擊退 |
| 彈道 | **牆反彈** | 射程 ×1.5，碰到場地邊緣（或行星、小行星）反彈 1 次；要搭穿透才好用 | 稜鏡：每次反彈分裂成 2 發 |
| 發射 | **反向** | 朝反方向也射一份 | 全向：前後左右 4 個方向 |
| 發射 | **蓄力** | **停火蓄力**：停止射擊時開始蓄力（2 秒蓄滿，Lv2 1.5 秒），再按下的第一發依蓄力程度變強（蓄滿傷害 ×5），之後照常連射 | 過載砲：無限穿透，飛到盡頭爆炸 |
| 命中 | **黏著** | 子彈黏在敵人身上（先打 30%）；第一發黏上後 2 秒一起爆炸（之後黏上的不重新計時），黏越多發倍率越高：×(1.5 ＋ 每發 0.1)，最多 ×3（Lv2 ×(2 ＋ 每發 0.15)，最多 ×4.5）；會穿透的子彈每穿過一隻留一份，穿甲用完才黏住；迴旋每打一隻留一份，照常折返 | 連鎖引爆：爆炸時立刻引爆周圍（90）敵人身上的子彈；要波及傷害就插巨彈 |
| 命中 | **感染** | 被擊殺的敵人爆出 3 發子彈（×1.5） | 瘟疫：爆出的子彈也帶感染（最多 2 代） |
| 命中 | **吸引** | 命中時把被打中那一隻附近的敵人拉到牠身邊（被打中的那一隻不動；環繞還在繞圈的子彈不會拉，放出去之後才會） | 引力漩渦：每命中 8 次生成一個漩渦 |
| 機體 | **衝刺射擊** | 衝刺結束時用整條電路朝準星額外開一槍（×1.5，Lv2 連開 2 槍；有停火蓄力會用掉） | 流星：衝刺的那一槍無限穿透，傷害 +100% |
| 命中 | **攔截** | 子彈碰到敵彈時把它打掉（跟打中敵人一樣扣 1 穿甲，沒有穿甲就消失；相位刃無限穿透不受影響），0.2 秒後從那裡用整條電路朝最近的敵人回射（Lv1 傷害 ×0.5、Lv2 ×1）。0.2 秒內在 300 以內再擋下的會用綠色電弧拉到第一顆的位置，合成同一次回射（更遠的另外集氣、各自回射）：每多擋 1 顆傷害 +30%，最多 ×4，倍率越高回射的子彈越大、越白（打王時彈幕越密，回射越像一發狙擊）；散彈、相位刃、電漿特別會攔 | 反射鏡：打掉的敵彈也反彈回去（傷害 ×2） |

### 插座與組件

- **插座**：武器開局 0 個，每打完一隻王 +1（打第三關的王時 2 個），最多 3 個；其他晶片（玩法晶片、觸發器）掉落時隨機 1～3 個（1 個 50%、2 個 35%、3 個 15%），卡片上的 ◇ 就是插座數。沙盒、靶場一律 3 個。
- **組件**拖進晶片的插座（不佔電路格，能量照算）；超過插座數的組件沒有作用（變灰）。晶片在電路上換位置時，插座上的組件跟著走；晶片拿回倉庫時，組件也退回倉庫。組件**不會升級**，拿到重複的就是多一個，也沒有倉庫被動。
- **插在武器上**：作用在射出的全部子彈，但倍增、巨彈的傷害加成只算直擊（迴旋回程、環繞放出、地雷衝出、加速／疾射 1.5 倍以上、反彈後、反向往後、蓄滿、衝刺、攔截回射、黏著爆炸、感染爆出這些產物不吃，要插在那個晶片上）；**不會**作用在觸發器的回響上。觸發器的插座也一樣：傷害加成只算回響的直擊。
- **插在觸發器上**：作用在回響上（跟插在武器上一樣）。
- **插在玩法晶片上**：只作用在那個晶片的「產物」：

| 晶片 | 產物（插在它上面的組件只作用在這裡） |
|---|---|
| 迴旋 | 折返之後的子彈 |
| 環繞 | 放出的那一波 |
| 佈雷 | 衝出去的地雷 |
| 加速 | 速度到 1.5 倍之後的子彈 |
| 疾射 | 速度 1.5 倍以上的那一段（掉到 1.5 倍以下，倍增等傷害加成就失效） |
| 牆反彈 | 第一次反彈之後的子彈 |
| 反向 | 往後射的那一份 |
| 蓄力 | 蓄滿的那一發 |
| 黏著 | 爆炸：倍增加在爆炸上；分裂 = 爆炸時噴出 3 發碎片；巨彈 = 爆炸波及周圍（50%）；穿甲 = 黏住前多穿 2 隻（多留 2 份） |
| 感染 | 爆出來的子彈 |
| 吸引 | 拉力：只能插巨彈（範圍 ×1.5） |
| 攔截 | 回射的子彈 |
| 衝刺射擊 | 衝刺那一槍 |

| 組件 | 效果 |
|---|---|
| 分裂模組 | 每發拆成 3 發扇形，每發 ×0.4 |
| 巨彈 | 每發傷害 +30%，體積 ×1.8、擊退變強 |
| 穿甲塗層 | 穿透 +2 |
| 威力倍增器 | 傷害 +100% |
| 超頻模組 | 射速 ×2，連續射擊 3 秒後過熱、停火 1.5 秒。**只能插在武器上** |
| 鏡像迴路 | 再來一次：插在武器（或觸發器）上 = 武器多射一次（回響多一份）；插在玩法晶片上 = 它的產物多一份（迴旋折返多一發、環繞放出的那一波多一份、黏著爆炸兩次…）；兩個鏡像 = 3 份。吸引不能插 |
| 爆裂彈頭 | 命中時爆炸（半徑 60，子彈傷害的 50%） |
| 燃燒彈頭 | 命中附加燃燒 3 秒，每秒是這一下傷害的 30% |
| 冰凍塗層 | 命中的敵人減速 40%，持續 2 秒（跟其他減速相加，最多 70%） |
| 電擊線圈 | 命中時 1 道電弧打附近另一隻（50%；附近沒有就打回目標 25%） |
| 破甲彈頭 | 命中的敵人 3 秒內受到的所有傷害 +25%（紅色準星）；跟感測器 4 層的弱點標記相加，最多 +50% |

**元素組件**（爆裂、燃燒、冰凍、電擊、破甲）跟武器升級的爆炸、燃燒、減速、電弧**相加**：例如電漿「新星」（爆炸 80%）再插爆裂 = 爆炸 130%，半徑取大的；軌道「磁暴線圈」（2 道）再插電擊 = 3 道。插在黏著上 = 爆炸時帶這些效果（爆裂再炸一圈）。盾衛照樣擋不住爆炸、電弧、燃燒。

同一個晶片上的組件，**插在哪個插座、誰先誰後結果都一樣**（例：散彈［巨彈、分裂］和［分裂、巨彈］都是 15 發大彈）。

- **傷害加成分兩種**：武器加成 = 武器（或觸發器）插座上的倍增、巨彈 +30%，加上蓄力、速度倍率、衝刺射擊，全部相加；晶片加成 = 插在玩法晶片上的倍增、巨彈，作用在同一下命中的全部相加。最終 = 基礎 ×（1 ＋ 武器加成）×（1 ＋ 晶片加成）。

### 觸發器（放在電路格，不會升級）

觸發時用武器再射一次**回響**（傷害 50%），**右邊的晶片只作用在回響上**（開火時不執行），最多巢狀 3 層。觸發器也有插座：插在上面的組件作用在回響上。環繞、蓄力、衝刺射擊不能放在觸發器右邊（變灰）。

| 觸發器 | 什麼時候觸發 |
|---|---|
| 命中觸發器 | 子彈命中敵人時，從命中點沿子彈原本的方向射（可以打到被命中的這一隻） |
| 消失觸發器 | 子彈消失時，從消失的位置沿子彈原本的方向射：飛完射程、穿甲用完、黏著引爆、地雷時間到、迴旋飛回飛船都算；被盾反彈、被地圖物件擋住、飛出場地不算 |
| 定時觸發器 | 子彈飛行中每 0.3 秒往左右兩側各射一次，每顆子彈最多 5 次（10 發）；停住的地雷不算 |

V1 的協同處理器、資料鏈結、共振器、彈射模組、冷卻管線、超頻核心、軍規複合晶片都拿掉了（巨大化、聚焦合併成巨彈）。黑洞融合（奇異點晶片、廢鐵）改成航圖節點「奇異點」：強化電路格（見「航圖與獎勵」）。

## 機體

### 飛船（開局配置）
船體數值相同（HP 100、速度 270、衝刺冷卻 0.9 秒），差別在開局帶什麼：

| 飛船 | 開局 |
|---|---|
| 先鋒號 | 沒有零件，零件格 7 格（其他 6 格） |
| 堡壘號 | 重裝甲 2 層（直接開啟厚甲） |
| 幻影號 | 輕裝甲 1 層、加速器 1 層 |
| **星門號** | HP 90、衝刺冷卻 1.2 秒。衝刺時在起點和落點開一對門（3 秒）：自己和隊友的子彈、飛船從門外走進門會從另一個門出來（門開在身上不會馬上傳送）；**敵彈也會穿門**，敵人不會 |

### 零件
每層小好處＋小代價，同種疊到 2 層、4 層開啟特性。零件格有限（6 格，擊沉旗艦 +1），要專心疊一種還是分散開好幾種，是主要的取捨。

| 零件 | 每層 | 2 層 | 4 層 |
|---|---|---|---|
| 重裝甲 | HP +20｜速度 −4% | 厚甲：單次受傷最多扣 20% 最大 HP | 衝撞：撞到敵人造成「層數 × 20」並撞飛，自己不受碰撞傷害 |
| 輕裝甲 | 衝刺冷卻 −8%｜受到的傷害 +3% | 偏折：被打到後無敵時間 +0.8 秒 | 反擊裝甲：被打到時朝打你的方向回射 8 發 |

**大地圖與區域**：一般戰、精英戰是一張不規則的大地圖，分成 2～3 個區域（一區一波）。每個區域由幾個大圓疊成（L 形、花生形、Y 形…），空地大約是方形場地的 2/3，邊緣坑坑窪窪；區域之間用短通道相連，通道中間有**閘門**。右上角有小地圖（整張地圖、閘門、敵人、飛船）。

- **牆**：擋住飛船、敵人和雙方的子彈。牆反彈的子彈照牆面的角度彈開（入射角 = 反射角）；其他子彈打到牆就消失（過載砲在牆上爆炸）；敵人的子彈也一樣，牆可以當掩護。環繞中的子彈、迴旋的回程、停住的地雷不受牆影響。敵人會繞牆追過來。
- **閘門**：這一區清完才打開（不在畫面裡時飛船旁邊有箭頭，照繞牆的路線指過去），地上的晶體全部吸過來。有人穿過閘門就開始下一區；穿過去之後不能回頭，敵人和子彈一律穿不過閘門（子彈打到閘門跟打到牆一樣）。雙人：一個人穿過去就開始，另一個人之後自己飛過去加入；倒下的人會被搬到新區域的入口，隊友才救得到。
- 敵人散在這一波的區域各處出生（離你至少 500，可能在牆後、在側邊），不會一起生在面前。最後一區清完就結束戰鬥。沙盒、靶場是方形場地（跟以前一樣）。
- **王關場地**：旗艦戰也是用同一套方法產生，只有一區、沒有閘門，大小跟方形場地差不多，形狀照王：星噬母艦是圓形大廳＋外圍 5 個小凹室；裂界獵艦是細長的菱形（衝鋒有距離，撞到牆就停）；終焉核心是圓形場地，中間四根柱子排成十字（可以擋彈幕）。王的子彈打到牆、柱子也會消失；王被牆擋住時會橫移找角度。
- **終焉核心的落點轟炸**：在最近的玩家身邊標 4 個紅圈（半徑 110，其中一個在腳下；暴走後 6 個），1.2 秒後爆炸，圈裡的飛船受 25 傷害，躲在柱子後面也會被炸。

## 👥 雙人連線

### 開房與開始
1. 一人按「開房間」，拿到 4 碼房號；另一人輸入房號按「加入房間」。
2. 兩人到齊後，房主按「開始」，兩人各自選飛船、武器與起始晶片。
3. 兩人都選好就開始遠征。每局結束後兩人回到同一個房間，隊友回到房間後房主才能再按開始。

1P ＝房主，2P ＝加入的隊友。

### 航圖與投票
- 星圖由房主產生，兩人看到的完全一樣。
- 點節點就是投票（節點上會標 1P／2P，可以改投）。
- 兩人都回到航圖後倒數 **20 秒**；兩人都投了就立刻出發。
- 兩人選不同節點時，**各 50% 抽籤**，畫面會顯示抽籤結果。時間到還沒投的人不算票；兩人都沒投就隨機。

### 錢包
- **每人一個錢包**，商店、補血、電路擴充、換零件都花自己的錢。
- **怪物掉落的晶體兩人都拿**：不管誰撿到，兩人都 +1。戰鬥結束時地上沒吸完的也一樣。
- 精英 +15、旗艦 +50：兩人各自拿。
- 跳過獎勵 +10、回收晶片、軍械台補償：只進自己的錢包。

### 獎勵與節點
- 戰鬥、精英、改裝廠、軍械台的獎勵，每人各自選。
- 商店、黑洞、維修站、改裝廠、軍械台各自進行（商店商品兩人各自隨機）。
- 打贏旗艦：兩人各得插槽 +1、零件格 +1，各自決定要不要裝旗艦模組；由房主決定前往下一星區或結束遠征。

### 戰鬥
- 敵人數量 ×2 → ×2.5、敵人血量 ×1 → ×1.3，照難度從第 1 星區開頭漲到第 3 星區最後（兩個人的配裝一起疊，後期成長比單人快；無盡模式停在 ×2.5／×1.3）。晶片的成長需求 ×1.25（兩個人都能打到同一隻，每人拿到的不是剛好一半）。隊友離線、房主一個人繼續時恢復成單人血量。
- 戰鬥中任何一人按 **Tab**，兩人一起暫停；另一人畫面顯示「隊友正在編輯電路」，也可以同時整理自己的電路。
- 被擊墜：倒下的飛船留在原地，周圍有救援圈。活著的隊友待在圈內（半徑 70）累積 2 秒就能救起來，救的人分出自己當前一半的血量給對方，救起後無敵 1.5 秒；離開圈子進度會慢慢退回。沒被救起的人在戰鬥結束後以 30% HP 歸隊。兩人都被擊墜才結束。
- 任何一人切到其他視窗或分頁，兩人一起暫停（瀏覽器會停住背景分頁的遊戲）。
- 星門號的傳送門兩人都能用：隊友被包圍時，可以從你的門撤出來。
- 小行星擋視野各算各的：你看不到的，隊友可能看得到。

### 斷線與重新連線
- **隊友斷線**：房主那邊暫停，房間保留 **120 秒**。房主可以選：
  - 等隊友回來；
  - **自己繼續玩**：隊友從場上移除，房間一直開著，隊友隨時用同一個房號回來就接上當下的進度；
  - 結束這一局（存下紀錄）。
- **隊友那邊**：自動重試一次，也可以按「重新連線」。就算重新整理了頁面，選「雙人連線」後輸入同一個房號也能回到這一局：電路、倉庫、插座數、奇異點強化的格子、零件、背包模組、晶片成長、錢包、血量、傷害統計都會從房主那邊還原，戰鬥中斷線會回到同一波。
- **房主斷線或重新整理**：這一局無法恢復（整局遊戲在房主的電腦上跑）。

### 畫面資訊
- 右上角「連線延遲」：兩台電腦之間來回一趟的時間（綠 < 80ms、黃 < 150ms、紅）。房主自己的操作沒有延遲，房主畫面上的隊友大約晚這個數字的一半。
- 左上角：自己的 HP、衝刺冷卻、蓄力／超頻熱度（有裝時）、錢包、背包模組，以及隊友的血條。
- 結算畫面：「雙人傷害結算」（兩人的傷害、占比、擊殺、最高單發）＋自己的傷害明細。每一擊都記在打出的人身上，擊殺算在補最後一刀的人身上。

## 🎯 靶場

用來確認晶片機制。電路一開始有 6 格空位，按 Tab 從晶片庫放晶片；「🚀 機體」分頁可以換飛船、武器、武器升級，直接加減零件層數、換背包模組。關掉編輯器時數據自動歸零，方便比較不同電路。

- 標靶打不死、不會動、不會攻擊，被擊退後會彈回原位。
- **1～4**：換標靶排列（單一／一排 8 個：看穿透／密集 19 個：看爆炸、分裂／散開 10 個：看追蹤、電弧）
- **6 爆量**：換成以前攔截爆量的那組散彈配裝（迴旋、環繞、攔截 Lv3…＋蟲群核心），10 個標靶圍在四周，每 1.5 秒一圈 32 發環形彈射向飛船（不扣血）
- **5**：實戰（原本的沙盒模式）：清掉標靶，改成一波波真的敵人，無限波次、越來越強（每 5 波精英、每 10 波旗艦）；飛船不會死（血量歸零時回滿）。按 1～4 回到標靶。數據面板照樣計算。
- **T**：慢動作 ×0.25　**R**：清除數據
- **生成敵人**（按鈕列第二排）：選敵人種類（全部敵人和三隻王）和難度（1／3／6／10／17，血量照那個難度），切換「不動／會動」（不動 = 跟標靶一樣不移動、不攻擊）和「打得死／打不死」；按 **G** 生在滑鼠指的位置（**Shift＋G** 一次 5 隻），按鈕列的「G 生成」生在飛船前方 300（手機用）；**C** 只清掉手動生的敵人；換標靶排列（1～4）時也會清掉。
- 右上角：實測 DPS（近 3 秒）與估算 DPS 對照、總傷害、命中次數、最高單發、傷害來源拆分、每發幾顆、每一層觸發展開幾顆。
- 畫面上方有按鈕列（1～5、R、T、生成敵人），滑鼠或觸控也可以切換。

### 畫面提示
- **粉紅外圈**：帶觸發器的子彈（觸發時才執行觸發器右邊的晶片）。
- **敵人身上的粉紅小點**：黏著的子彈數。**紅色準星**：弱點標記中。
- 例：「相位刃 → 命中觸發器［分裂］」＝開火 2 片刃（帶觸發）；命中時用 50% 傷害再射一次，那一次才分裂成 6 片（分裂插在觸發器上 = 作用在回響）。

## 遊玩紀錄

標題畫面「📜 遊玩紀錄」。只存在這台裝置的瀏覽器裡（最近 50 筆），可以單筆或全部複製成文字，也可以「🗑 刪除所有紀錄」（畫面上會再確認一次）。V2 的紀錄和 V1 分開存。

每筆紀錄有 `mech`：零件層數、零件格、背包模組、開啟的特性、各晶片的用量成長。

「📋 複製這局紀錄」「📋 複製這筆」複製的是**精簡文字**（約 700 字，沒有 JSON 符號，貼到聊天軟體不會被轉成表情）；「複製全部紀錄」是完整 JSON（備份用）。

### 遊玩紀錄的代號

| 類別 | 代號 |
|---|---|
| 結果 | 死、通（通關）、退（中途結束）、斷線、進行中 |

| 被打 | 敵人代號＋「彈」（子彈）或「撞」（撞擊），例如「噴彈」「核撞」 |

傷害數字都是完整數字，不簡寫。

晶片傷害的歸屬：
- 反向只算多射出來的子彈。
- 黏著、佈雷、迴旋的回程、環繞放出／加速／疾射的速度倍率這些命中後才發生的加成，記在各自的晶片上。
- 伏擊網的電弧、感染爆出的子彈、攔截回射、衝刺射擊那一槍，基礎傷害也算在各自的晶片上。

雙人局在這些情況自動存一筆：兩人都被擊墜、結束遠征、戰鬥中斷線、中途離開。雙人紀錄另外有：
- `coop.role`：房主／隊友；`coop.mate`：隊友的配裝
- `coop.ping`：延遲平均、最低、90% 以內、最高、量測次數
- `coop.sync.maxGapMs`：同步訊息最長間隔（暫停中不算）。數字很大代表那段時間對方的遊戲停住了（例如切到背景）
- `coop.team`：兩人的傷害、擊殺、最高單發

### 連線
- **WebRTC 點對點**（PeerJS 1.5.4，從 jsDelivr 載入）。PeerJS 的公開伺服器只負責配對，遊戲資料直接在兩台電腦之間傳，不經過伺服器。房號對應的 Peer ID 是 `circuitrogue-mp-XXXX`。
- 少數網路環境（某些公司網路、行動網路的共享 IP）打不通直連；目前沒有中繼伺服器（TURN）。
- 和配對伺服器斷線時（常見於切到背景一陣子）房主會自動重新登記房號，兩人之間的連線不受影響。
