# 星環電路 Circuit Rogue：雙人連線版（實驗）

線上遊玩：<https://yang8629.github.io/space_rogue_multiplayer/>

單一 HTML 檔（Canvas + 原生 JavaScript）的太空 roguelite。以單人版為基礎，加上兩人合作遠征、靶場，以及開局三選一的起始晶片。

目前版本：**mp-0.6.3（2026-09-27）**。版號顯示在標題畫面最下方與大廳；兩人的版號不同時不能開始，請兩邊都按 Ctrl+F5 重新整理。

---

## 模式

| 模式 | 內容 |
|---|---|
| 開始遠征 | 單人：三個星區（各一隻旗艦），打完可選無盡模式 |
| 沙盒模式 | 單人：無盡波次，晶片無限供應，可隨時改武器升級 |
| 🎯 靶場 | 單人：固定標靶，用來確認晶片機制與 DPS（見下方） |
| 👥 雙人連線 | 兩人合作遠征（見下方） |

## 開局

飛船 → 武器 → **三選一起始晶片**（遠征與雙人）。起始晶片直接裝在電路第 2 格（武器右邊）。飛船不再自帶晶片。沙盒與靶場不選起始晶片。

### 和單人原版不同的數值
| 項目 | 原版 | 雙人版 |
|---|---|---|
| 相位刃（基礎） | 5 段 × 7 傷害（一次 35） | **3 段 × 10 傷害（一次 30）** |
| 相位刃・巨刃 | 7 段 | **5 段** |
| 相位刃・旋風斬 | 12 段 | 12 段（不變） |

## 👥 雙人連線

### 開房與開始
1. 一人按「開房間」，拿到 4 碼房號；另一人輸入房號按「加入房間」。
2. 兩人到齊後，房主按「開始」，兩人各自選飛船、武器與起始晶片。
3. 兩人都選好就開始遠征。每局結束後兩人回到同一個房間，隊友回到房間後房主才能再按開始。

1P ＝房主，2P ＝加入的隊友。

### 航圖與投票
- 星圖由房主產生，兩人看到的完全一樣。
- 點節點就是投票（節點上會標 1P／2P，可以改投）。
- 兩人都回到航圖後倒數 **20 秒**；兩人都投了就立刻出發。
- 兩人選不同節點時，**各 50% 抽籤**，畫面會顯示抽籤結果。時間到還沒投的人不算票；兩人都沒投就隨機。

### 錢包
- **每人一個錢包**，商店、補血、拆廢鐵、電路擴充都花自己的錢。
- **怪物掉落的晶體兩人都拿**：不管誰撿到，兩人都 +1。戰鬥結束時地上沒吸完的也一樣。
- 精英 +15、旗艦 +50：兩人各自拿。
- 跳過獎勵 +10、回收晶片、軍械台補償：只進自己的錢包。

### 獎勵與節點
- 戰鬥、精英、軍械台的獎勵，每人各自三選一。
- 商店、黑洞、維修站、軍械台各自進行（商店商品兩人各自隨機）。
- 打贏旗艦：兩人各得插槽 +1；由房主決定前往下一星區或結束遠征。

### 戰鬥
- 敵人血量 ×1.6（暫定）。隊友離線、房主一個人繼續時恢復成單人血量。
- 戰鬥中任何一人按 **Tab**，兩人一起暫停；另一人畫面顯示「隊友正在編輯電路」，也可以同時整理自己的電路。
- 被擊墜：倒下的飛船留在原地，周圍有救援圈。活著的隊友待在圈內（半徑 70）累積 2 秒就能救起來，救的人分出自己當前一半的血量給對方，救起後無敵 1.5 秒；離開圈子進度會慢慢退回。沒被救起的人在戰鬥結束後以 30% HP 歸隊。兩人都被擊墜才結束。
- 任何一人切到其他視窗或分頁，兩人一起暫停（瀏覽器會停住背景分頁的遊戲）。

### 斷線與重新連線
- **隊友斷線**：房主那邊暫停，房間保留 **120 秒**。房主可以選：
  - 等隊友回來；
  - **自己繼續玩**：隊友從場上移除，房間一直開著，隊友隨時用同一個房號回來就接上當下的進度；
  - 結束這一局（存下紀錄）。
- **隊友那邊**：自動重試一次，也可以按「重新連線」。就算重新整理了頁面，選「雙人連線」後輸入同一個房號也能回到這一局：電路、倉庫、奇異點、錢包、血量、傷害統計都會從房主那邊還原，戰鬥中斷線會回到同一波。
- **房主斷線或重新整理**：這一局無法恢復（整局遊戲在房主的電腦上跑）。

### 畫面資訊
- 右上角「連線延遲」：兩台電腦之間來回一趟的時間（綠 < 80ms、黃 < 150ms、紅）。房主自己的操作沒有延遲，房主畫面上的隊友大約晚這個數字的一半。
- 左上角：自己的 HP、衝刺冷卻、錢包，以及隊友的血條。
- 結算畫面：「雙人傷害結算」（兩人的傷害、占比、擊殺、最高單發）＋自己的傷害明細。每一擊都記在打出的人身上，擊殺算在補最後一刀的人身上。

## 🎯 靶場

用來確認晶片機制。電路一開始有 6 格空位，按 Tab 從晶片庫放晶片、切換武器升級；關掉編輯器時數據自動歸零，方便比較不同電路。

- 標靶打不死、不會動、不會攻擊，被擊退後會彈回原位。
- **1～4**：換標靶排列（單一／一排：看穿透／密集：看爆炸、分裂／散開：看彈射、追蹤、電弧）
- **T**：慢動作 ×0.25　**R**：清除數據
- 右上角：實測 DPS（近 3 秒）與估算 DPS 對照、總傷害、命中次數、最高單發、傷害來源拆分、每發幾顆、每一層命中觸發展開幾顆。
- 目前只支援鍵盤。

### 畫面提示
- **粉紅外圈**：帶「命中觸發」的子彈（命中時才執行觸發器右邊的晶片）。
- **相位刃**畫成往前凸的弧形；帶命中觸發的刃改用中心與兩端的粉紅點標示（大圈會把刃整個包住，看起來像圈圈）。
- 例：「相位刃 → 命中觸發器 → 分裂」＝開火 3 片刃（帶觸發）；命中時用 50% 傷害再射一次，那一次才分裂成 9 片。

## 遊玩紀錄

標題畫面「📜 遊玩紀錄」。只存在這台裝置的瀏覽器裡（最近 50 筆），可以單筆或全部複製成文字，也可以「🗑 刪除所有紀錄」（畫面上會再確認一次）。

雙人局在這些情況自動存一筆：兩人都被擊墜、結束遠征、戰鬥中斷線、中途離開。雙人紀錄另外有：
- `coop.role`：房主／隊友；`coop.mate`：隊友的配裝
- `coop.ping`：延遲平均、最低、90% 以內、最高、量測次數
- `coop.sync.maxGapMs`：同步訊息最長間隔（暫停中不算）。數字很大代表那段時間對方的遊戲停住了（例如切到背景）
- `coop.team`：兩人的傷害、擊殺、最高單發

## 技術說明

### 檔案結構
`index.html` 只有 HTML 骨架，依序載入下面的檔案（一般的 `<script>`，共用同一個全域範圍；後面的檔案會用到前面定義的東西）。改功能時只要打開相關的檔案。

| 資料夾 | 檔案 | 內容 |
|---|---|---|
| `css/` | `style.css` | 樣式 |
| `js/core/` | `config.js` | 設定值 `CFG`（含版號）、共用小工具 |
| | `core.js` | 子彈資料格式、增幅相加、傷害歸屬 |
| | `pipeline.js` | 電路執行器（編譯電路、產生子彈、估算 DPS）、倉庫被動 |
| | `main.js` | 啟動與主迴圈 |
| `js/data/` | `weapons.js` | 5 把武器與兩段升級樹 |
| | `chips.js` | 晶片定義、等級、合成升級、黑洞融合、起始電路 |
| | `ships.js` | 3 艘飛船 |
| | `map.js` | 航圖節點與星圖產生 |
| `js/game/` | `entities.js` | 玩家飛船、子彈、敵人與旗艦技能 |
| | `game.js` | 一局的流程、戰鬥、獎勵、商店、黑洞、主更新 |
| | `range.js` | 🎯 靶場 |
| | `effects.js` | 粒子、浮動數字 |
| `js/system/` | `input.js` | 鍵盤滑鼠、觸控雙搖桿、畫面尺寸 |
| | `audio.js` | 音效、背景音樂（Web Audio 即時合成） |
| | `net.js` | 雙人連線：大廳、同步、投票、錢包、斷線重連、雙人紀錄 |
| `js/ui/` | `render.js` | 戰鬥畫面繪圖、HUD、靶場面板 |
| | `screens.js` | 標題、選單、航圖、獎勵、商店、結算、紀錄等畫面 |
| | `editor.js` | 電路編輯器（Tab；靶場多一個「機體・武器」分頁） |
| | `codex.js` | 📖 電路總覽 |
| | `mechcheck.js` | 42 項機制觸發檢查 |

### 連線
- **WebRTC 點對點**（PeerJS 1.5.4，從 jsDelivr 載入）。PeerJS 的公開伺服器只負責配對，遊戲資料直接在兩台電腦之間傳，不經過伺服器。房號對應的 Peer ID 是 `circuitrogue-mp-XXXX`。
- 少數網路環境（某些公司網路、行動網路的共享 IP）打不通直連；目前沒有中繼伺服器（TURN）。
- 和配對伺服器斷線時（常見於切到背景一陣子）房主會自動重新登記房號，兩人之間的連線不受影響。

### 誰負責什麼
| 房主（1P） | 隊友（2P） |
|---|---|
| 模擬整個戰場：敵人、所有子彈、傷害判定、掉落 | 自己的移動、衝刺在自己電腦上算（零延遲），每秒 30 次把位置與「有沒有按開火」傳給房主 |
| 替隊友開火時，用 `Game.withLoadout` 暫時換上隊友的武器與電路 | 回到航圖或關掉編輯器時，把配裝（電路、倉庫、武器升級、奇異點定義、血量、錢包）傳給房主 |
| 每秒 30 次傳戰場快照（只傳隊友附近的子彈；約 1KB） | 兩次快照之間照速度推算位置；晶體用和房主同一套吸引規則自己模擬 |
| 產生星圖、決定投票結果、判定勝負與擊墜 | 商店、獎勵、黑洞等節點在自己電腦上處理 |
| 記兩人各自的傷害，每秒同步一次 | |

### 訊息一覽（JSON）
| 類別 | 訊息 |
|---|---|
| 大廳 | `hello`（含版號，重連時含 `resume`）、`welcome`、`ver`、`full`、`room`、`pick`、`ready`、`start` |
| 戰鬥 | `i`（隊友操作）、`s`（戰場快照）、`dmg`（傷害統計）、`won`、`over`、`edit`（Tab 暫停） |
| 遠征 | `at`（回到航圖）、`vote`、`vt`（倒數）、`go`、`lo`（隊友配裝）、`sector`、`finish` |
| 其他 | `ping`／`pong`、`away`（切到背景）、`resume`／`back`（斷線重連） |

對方傳來的資料一律當成不可信：晶片 id、武器、星圖格式、數值範圍都會先檢查，不認得的晶片變成空格。

### 測試
開發時用 Node.js 跑的自動測試（不放在這個 repo）：
- **端對端**：兩份獨立的遊戲（房主、隊友）用模擬網路互連，從選配裝打完星區 1 進到星區 2，並測試錢包、Tab 暫停、配裝同步、斷線重連（同一頁面、重新整理、戰鬥中重新整理）、房主自己繼續後隊友回來。
- **靶場**：標靶打不死、實測 DPS 與估算相近、快捷鍵。
- **單人機制檢查**：42 項（武器、晶片、敵人行為），確認雙人的改動沒有影響單人。
