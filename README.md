# 星環電路 Circuit Rogue：多人連線版 V2（實驗）

線上遊玩（V2）：<https://yang8629.github.io/space_rogue_multiplayer/>

單一頁面（Canvas + 原生 JavaScript）的太空 roguelite，可以單人玩，也可以兩人合作遠征。

目前版本：**v0.1.3（2026-10-24 00:04）**。版號顯示在基地（主畫面）最下方與大廳；兩人的版號不同時不能開始，請兩邊都按 Ctrl+F5 重新整理。

## 玩法重點

重點是**改變玩法**，不是把數字疊高：

| 系統 | 內容 |
|---|---|
| 晶片 | 13 個改變玩法的晶片（迴旋、環繞、佈雷……）；數值晶片改成**組件**，插在晶片的**插座**上讓它升級（插 2 個進化）；3 種觸發器 |
| 機體 | 飛船改成「開局配置」＋專屬能力，之後靠**零件**（5 種，疊層數開特性）長出流派 |
| 飛船 | 新飛船**星門號**（衝刺開一對傳送門）、**哨兵號**（衝刺留下砲台） |
| 航圖 | 新節點**改裝廠**（零件）；旗艦多給零件格 |
| 戰場 | **地圖物件**：行星、黑洞、彗星、小行星帶 |

## 基地（主畫面）

打開遊戲就是基地：一座分區的太空站，開著飛船在裡面走（WASD 移動、Space 衝刺（跟戰鬥一樣有飛船能力的樣子：先鋒號瞬移、幻影號留殘影、星門號開一對門、哨兵號留砲台打標靶機；基地沒有敵人，殘影不吸引火力）、按住左鍵用裝備的武器射著玩：軍械庫有 3 個標靶機，打中跳傷害數字、靶上面顯示最近 3 秒的每秒傷害；多人房間裡大家的子彈互相看得到，被別人打中會被推開、閃一下，不會掉血），靠近東西按 **E**（或 Enter）。中間是中央大廳（進基地時在正中間；多人連線和靶場的終端機），大廳下面延伸出去是發射甲板（發射台，跑道通到太空），左翼機庫（停機位繞著中間的轉盤排一圈）、右翼軍械庫，上面一排晶片實驗室、觀景台、戰績室；房間之間有牆，從開口過去（大廳有開口直接通到每間房），鏡頭跟著飛船。上方是總覽（解鎖了幾樣、完成局數、擊殺、最遠星區）和「📖 電路總覽」「⚙ 設定」；靠近的東西在右下角有說明卡。

**⚙ 設定**（基地上方，或戰鬥中按 Esc 的選單）：主音量、音樂音量、音效／音樂開關、畫面震動、顯示 FPS、卡片預設顯示完整說明、按鍵一覽、版本與清暫存重新整理。設定存在這台裝置的瀏覽器。

| 地方 | 按 E |
|---|---|
| 機庫的停機位（5 艘飛船） | 換成那艘船，留在原地（說明卡寫能力、數值、開局零件；沒解鎖的是剪影，寫條件和進度，換不過去） |
| 軍械庫的武器架（6 把武器） | 裝備那把武器：武器從架子拿下來裝在船頭（說明卡寫數值、三條升級路線；沒解鎖的是暗的，寫條件和進度，裝不了）。按 Q：電路總覽的武器頁、捲到這把的升級路線（沒解鎖的也能看） |
| 🚀 發射台 | 選章（沒解鎖的灰掉）→ 出發 → 起始晶片三選一（隨機，出發後才抽）→ 出發動畫（飛船開上發射台、蓄能、沿跑道衝出去） |
| ⚔ 武器資料（軍械庫的操作台） | 6 把武器的說明、數值、三條升級路線 |
| ◈ 晶片庫（晶片實驗室的操作台） | 玩法晶片、組件、觸發器（按 Shift 看詳細）；玩法晶片寫累計的玩法擊殺 |
| 🏆 戰績（戰績室的操作台） | 累計成績、章節、每隻旗艦打倒幾次、玩法擊殺排行、所有遊玩紀錄 |
| 👥 多人連線、🎯 靶場（終端機） | 開房間／加入；用現在開的船、裝的武器進靶場（多人房間裡不能用） |

剛解鎖、還沒看過的東西，停機位、武器架和操作台上會亮「新」：靠近那個停機位、武器架，或打開那個操作台就算看過。

## 模式

| 模式 | 內容 |
|---|---|
| 🚀 出發 | 單人：在基地的發射台選章出發，用現在開的飛船；每章打一段星區，打完可選無盡模式（見下方「章節」） |
| 🎯 靶場 | 單人：晶片無限供應，可隨時改武器、零件；固定標靶看數據，或按 5 切換「實戰」打一波波真的敵人（見下方） |
| 👥 多人連線 | 2～4 人合作遠征（見下方） |

開局：在基地換好飛船（停機坪）、武器（武器架）→ 發射台出發 → **三選一起始晶片**（遠征與多人），起始晶片直接裝在電路第 2 格。沙盒與靶場不選起始晶片。

## 武器

左鍵是基本攻擊，**右鍵是這把武器的招牌動作**（有右鍵的武器，衝刺只用 Space）。每把武器各有三條升級路線（軍械台：第一段 3 選 1、第二段 2 選 1），升級都是加深這把武器自己的玩法。數值、升級內容看遊戲裡的「武器資料」。

| 武器 | 左鍵 | 右鍵 |
|---|---|---|
| 熱能光束 | 高射速光束；每發加熱，熱度滿了過熱停火，停火一下才開始降溫；連射四快一慢，慢的那發前後各停一拍、又大又痛 | **排熱**：熱度夠了才能用，把熱度噴成一圈衝擊波（越熱越痛），清掉身邊的敵彈 |
| 迴旋飛輪 | 擲出飛輪，飛到盡頭停在原地旋轉一段時間，碰到的敵人一直受傷，時間到自己飛回手上（回程也打得到），也可以開過去撿起來；場上有上限；丟滿再召回、全部接回，下一擲又快又痛 | **召回**：全部飛輪直線飛回手上，回程更痛、無限穿透 |
| 重力井 | 重力彈飛到盡頭變成重力井，把附近的敵人吸過去（旗艦不吸）；場上有上限；新的井停在舊井範圍裡會疊成大井 | **塌縮**：所有重力井一起爆炸，範圍內敵人越多越痛（有上限；旗艦照體型算好幾隻） |
| 牽引鉤 | 鉤爪勾住敵人拉到飛船前方；旗艦勾不動，改成釘在牠身上持續撕扯；勾住的、甩出去的敵人擋子彈（牠照樣扣血）；多人時也勾得到隊友（戰鬥和房間都行；衝刺掙脫、右鍵甩出去撞敵人）；勾住時左鍵改成扯，第三扯重摔 | **甩擊**：把勾住的敵人甩出去砸別隻（兩隻都受傷）；釘住旗艦時是用力一扯 |
| 能量刃 | 近戰三段連段（橫斬 → 反手斬 → 重斬，重斬往前突進） | **彈反**：抓準時機格擋，碰到的敵彈反射回去，成功後冷卻轉好、下一刀變強化的重斬 |
| 無人機蜂群 | 按住射擊時無人機飛到準星附近自動開火（離飛船有距離上限）；飛出去會被敵彈打壞、之後重生 | **收攏**：無人機繞成一圈護盾，擋下一定數量的敵彈，這段時間不攻擊 |

## 晶片

電路由左至右執行，第 1 格固定是武器。玩法晶片作用在它左邊已經產生的子彈（貼在子彈上的特性，分裂複製子彈時會一起複製）。**組件**（分裂、巨彈、穿甲、倍增、超頻、鏡像、爆裂、燃燒、冰凍、電擊）插進武器、玩法晶片或觸發器的**插座**（晶片卡下面的圓，不佔電路格），見下面「插座與組件」。**觸發器**右邊的晶片只作用在觸發後射出的回響上。

### 改變玩法的晶片（插組件升級）

| 類型 | 晶片 | Lv1 | Lv3 進化 |
|---|---|---|---|
| 彈道 | **迴旋** | 一定會飛回來：打中敵人（有穿甲時穿甲用完）就穿過去再折返，回程再打牠一次；撞到牆（方形場地的邊緣）、行星、小行星，或飛到射程盡頭也折返。回程追著射出它的飛船、一路無限穿透（傷害 ×0.7）。相刃（無限穿透）：刃片揮到盡頭就飛回來 | 迴旋風暴：折返時分裂成 3 發 |
| 彈道 | **環繞** | 按住射擊時子彈存在飛船旁繞圈（Lv1 最多 10 發、Lv2 20 發，一次開火算一發（一次射好幾顆的全部算一發），碰到敵人照打；同一隻隔 0.5 秒可再打，每打一次扣一次穿甲，用完消失；還按著就補上，每次開火補一發），越繞越快；放開射擊時全部從所在位置朝滑鼠那一點射出（衝刺不會放出；存滿後按住不再射），轉越快放出越快：Lv1 3 秒轉滿（速度與傷害 ×1.5），Lv2 2 秒轉滿（×2）。觸發射出的子彈不進圈。搭加速：從放出時的倍率繼續加上去（不相乘） | 星環：射出的子彈追蹤敵人 |
| 彈道 | **佈雷** | 子彈飛到射程一半時停住變成地雷（4 秒，Lv2 6 秒）：敵人的邊緣進到 50（Lv2 70）內就用武器原本的速度朝牠衝出去，跑完剩下的射程（至少比觸發範圍遠 30），加速接著停住前的進度算（大隻的敵人在旁邊也會觸發），傷害 ×1.2；時間到沒被觸發就消失。不擋子彈。搭迴旋：衝出去打中後折返，用武器原本的速度飛回 | 伏擊網：每顆地雷和最近的 2 顆（110 以內）之間拉出電弧 |
| 彈道 | **加速** | 子彈出手只有 0.5 倍速，越飛越快，射程 ×1.5。速度照「飛了射程的幾成」算：出手 0.5 倍，射程盡頭 3 倍（Lv2 4 倍），每把武器都一樣（遠近照各自的射程換算）；速度倍率加進傷害加成，近距離虧、遠距離痛。搭環繞：從放出時的倍率繼續加；搭佈雷、迴旋：衝出去、回程接著原本的進度算 | 超音速：2 倍速以上無限穿透 |
| 彈道 | **牆反彈** | 射程 ×1.5，碰到場地邊緣（或行星、小行星）反彈 1 次；要搭穿透才好用 | 稜鏡：每次反彈分裂成 2 發 |
| 發射 | **反向** | 朝反方向也射一份 | 全向：前後左右 4 個方向 |
| 發射 | **蓄力** | **停火蓄力**：停止射擊時開始蓄力（2 秒蓄滿，Lv2 1.5 秒），再按下的第一發依蓄力程度變強（蓄滿傷害 ×5），之後照常連射 | 過載砲：無限穿透，飛到盡頭爆炸 |
| 命中 | **黏著** | 子彈黏在敵人身上（先打 30%）；第一發黏上後 2 秒一起爆炸（之後黏上的不重新計時），黏越多發倍率越高：×(1.5 ＋ 每發 0.1)，最多 ×3（Lv2 ×(2 ＋ 每發 0.15)，最多 ×4.5）；會穿透的子彈每穿過一隻留一份，穿甲用完才黏住；迴旋每打一隻留一份，照常折返 | 連鎖引爆：爆炸時立刻引爆周圍（90）敵人身上的子彈；要波及傷害就插巨彈 |
| 命中 | **感染** | 被擊殺的敵人爆出 3 發子彈（×1.5） | 瘟疫：爆出的子彈也帶感染（最多 2 代） |
| 命中 | **吸引** | 命中時把被打中那一隻附近的敵人拉到牠身邊（被打中的那一隻不動；環繞還在繞圈的子彈不會拉，放出去之後才會） | 引力漩渦：每命中 8 次生成一個漩渦 |
| 機體 | **衝刺射擊** | 衝刺結束時用整條電路朝準星額外開一槍（×1.5，Lv2 連開 2 槍；有停火蓄力會用掉） | 流星：衝刺的那一槍無限穿透，傷害 +100% |
| 機體 | **架設** | 站著不動時越射越快：站 2 秒疊滿，每層射速 +10%，最多 +60%（Lv2 +80%）；移動或衝刺就歸零（0.15 秒內不算） | 要塞：滿層時子彈穿透 +1、擊退 ×2 |
| 命中 | **攔截** | 子彈碰到敵彈時把它打掉（跟打中敵人一樣扣 1 穿甲，沒有穿甲就消失；能量刃的刃片無限穿透不受影響），0.2 秒後從那裡用整條電路朝最近的敵人回射（Lv1 傷害 ×0.5、Lv2 ×1）。0.2 秒內在 300 以內再擋下的會用綠色電弧拉到第一顆的位置，合成同一次回射（更遠的另外集氣、各自回射）：每多擋 1 顆傷害 +30%，最多 ×4，倍率越高回射的子彈越大、越白（打王時彈幕越密，回射越像一發狙擊）；散彈、相位刃、電漿特別會攔 | 反射鏡：打掉的敵彈也反彈回去（傷害 ×2） |

- **組件升級**：玩法晶片的等級 ＝ 1 ＋ 插在它上面的組件數，最多 Lv3（插 2 個就**進化**，改名、玩法再變一次；第 3 個組件只有效果、不再升級）。隨時可以在電路編輯器拔插，等級跟著變；移到倉庫就回到 Lv1。
  - 任何組件都算，插了沒效果的也算（吸引只有巨彈有效果、超頻模組和收束透鏡只有插在武器上才有效果），編輯器標「只升級，沒有效果」；超過插座數、沒電的組件不算。
  - 組件插武器（作用在全部子彈）還是插晶片（只作用在產物，但能升級）自己決定；晶片的插座數（1～3）決定最高等級。
  - 插上去升級時，說明框會顯示「升到 Lv2」「進化 → 迴旋風暴」。
- **玩法擊殺**：照著晶片的玩法打中敵人時，在牠身上貼這個晶片的標記（1 秒，再打中重新計時）；牠死掉時每個標記各記一次（子彈再多也只算一次）。旗艦召喚的小怪、精英召喚的蟲群、母巢生的蟲群不算。遊玩紀錄會列出各晶片的玩法擊殺數。

| 晶片 | 什麼時候貼標記 |
|---|---|
| 迴旋 | 回程打中 |
| 環繞 | 繞圈時碰到，或放出後打中 |
| 佈雷 | 地雷衝出去打中 |
| 加速 | 2 倍速以上打中 |
| 牆反彈 | 反彈過的子彈打中 |
| 反向 | 反向多射出來的子彈打中 |
| 蓄力 | 蓄滿的那一發打中 |
| 黏著 | 黏著爆炸 |
| 感染 | 爆出的子彈打中 |
| 吸引 | 被拉過 |
| 衝刺射擊 | 衝刺那一槍打中 |
| 架設 | 滿層時射出的子彈打中 |
| 攔截 | 回射的子彈（含反射鏡反彈的敵彈）打中 |

### 稀有晶片

- 玩法晶片＋1 個**詞條**（詞條 Lv1 70%、Lv2 25%、Lv3 5%）。卡片是金框、金色色帶、流光，電路格有 ★。
- **出現**：一般戰鬥的三選一每一格玩法晶片 4%；精英、旗艦的三選一保證一格（刷新也保證）；一般戰鬥打掉寶藏無人機、亂入的精英（見「戰鬥中的變化」）也各保證一格（同一場可以疊）。**擊沉旗艦先三選一**，選完（或跳過）才到勝利畫面領旗艦獎勵。三選一有稀有晶片時，其他卡先翻開，稀有那格醞釀一下（不能按）最後才翻開。
- **身上已經有這個晶片也會出現**：拿了之後身上那個變稀有，留在原本的格子、插座上的組件不動、插座數取兩個裡比較多的，不用倉庫格。已經有詞條時：同一個詞條 +1 級（最多 3）；不同詞條可以選「替換」（新詞條從 Lv1）或「增強」（原本的 +1 級）。
- 詞條是「照這個晶片的玩法打出成果」時的獎勵（數字是 Lv1／Lv2／Lv3）：

| 詞條 | 時機 | 效果 |
|---|---|---|
| 餘波 | 發動時（冷卻 0.5 秒） | 在發動的位置炸一圈震波：推開敵人，造成武器 50% 的傷害（半徑 80／100／120） |
| 淨空 | 發動時（冷卻 0.5 秒） | 清掉發動位置周圍的敵彈（半徑 60／90／120） |
| 迅捷 | 發動時（冷卻 0.5 秒） | 衝刺冷卻 −0.15／0.25／0.35 秒 |
| 狂熱 | 玩法擊殺 | 3 秒內射速 +6／9／12%（最多 5 層） |
| 爆發 | 發動時充能 | 照常使用約 10／8／6 秒充滿：用整條電路朝四周 8 個方向開槍 |
| 反擊 | 受傷時（冷卻 2 秒） | 這個晶片強制發動一次（見下表） |
| 結晶 | 玩法擊殺 | 每 10／8／6 次得 1 層護盾（擋下一次傷害，最多 1 層） |
| 收割 | 玩法擊殺 | 回 0.5／0.75／1 HP（每秒最多 3） |

- **發動**：迴旋折返、環繞放出、地雷衝出去、加速越過 2 倍速、反彈（場地邊緣、行星、小行星）、反向射出、蓄滿射出、黏著爆炸、感染爆出、吸引拉到敵人、衝刺射擊、架設疊滿後的第一發、攔截擋下敵彈。
- **爆發的充能**照每個晶片平常每秒發動幾次算（熟練電腦實測、舊的 5 把武器的中位數：迴旋 5、環繞 2.9、反向 2.1、吸引 2.35、加速 1.2、牆反彈 1.2、佈雷 0.84、黏著 0.75、感染 0.48、衝刺射擊 0.28、攔截 0.2、蓄力 0.1、架設 0.03）。
- **反擊**（每個晶片的強制發動）：迴旋 → 飛出去的全部折返；環繞 → 繞圈的全部放出；佈雷 → 停住的地雷朝最近的敵人衝出去；加速 → 飛行中的子彈速度倍率 +1.5；牆反彈 → 還能反彈的子彈原地反彈一次；反向 → 用整條電路朝後面開一槍；蓄力 → 下一發直接蓄滿；黏著 → 黏著的子彈立刻爆炸；感染 → 從飛船爆出子彈（整條電路，3 發，Lv2 起 5 發）；吸引 → 把最近那隻附近的敵人拉到牠身邊；衝刺射擊 → 馬上開一次衝刺射擊；架設 → 直接疊滿；攔截 → 朝最近的敵人回射一次。
- 多人：詞條由房主算，每個人、每個晶片各自冷卻、充能。

### 能量與容量

- 每個晶片、組件右上角的 ⚡ 是能量；機體有**能量容量**。倉庫裡的不吃電。
- **從左往右供電**：武器插座上的組件 → 第 1 格晶片 → 它插座上的組件 → 第 2 格晶片 → …，一個一個扣容量。
- 遇到**第一個電不夠的**，它和它右邊的全部**沒電、沒有作用**（不會跳過去找便宜的）；沒電的組件不算等級。編輯器上沒電的會變暗，第一個沒電的前面有「⚡ 斷電」線。重要的放左邊。
- 放錯位置、插座不夠這類本來就沒作用的不吃電；但插在玩法晶片上放錯的照樣吃電（它算等級）。能量**不影響射速**。
- 容量的來源：飛船開局（先鋒號 7、堡壘號 6、幻影號 7、星門號 8、哨兵號 7）、補給站每間可以買 +2、散熱片零件每層 +2。

### 插座與組件

- **插座**：武器開局 1 個（開局選到組件會直接插在武器上），每打完一隻王 +1，最多 3 個；其他晶片（玩法晶片、觸發器）掉落時隨機 1～3 個（1 個 50%、2 個 35%、3 個 15%），卡片上的 ◇ 就是插座數，卡片的框色也照插座數（1 個灰、2 個藍、3 個紫）。沙盒、靶場一律 3 個。
- **組件**拖進晶片的插座（不佔電路格，能量照算）；超過插座數的組件沒有作用（變灰）。晶片在電路上換位置時，插座上的組件跟著走；晶片拿回倉庫時，組件也退回倉庫。組件本身**不會升級**，拿到重複的就是多一個，也沒有倉庫被動；插在玩法晶片上讓那個晶片升一級（見上面「組件升級」）。
- **插在武器上**：作用在射出的全部子彈，但倍增、巨彈的傷害加成只算直擊（迴旋回程、環繞放出、地雷衝出、加速 1.5 倍以上、反彈後、反向往後、蓄滿、衝刺、攔截回射、黏著爆炸、感染爆出這些產物不吃，要插在那個晶片上）；**不會**作用在觸發器的回響上。觸發器的插座也一樣：傷害加成只算回響的直擊。
- **插在觸發器上**：作用在回響上（跟插在武器上一樣）。
- **插在玩法晶片上**：只作用在那個晶片的「產物」：

| 晶片 | 產物（插在它上面的組件只作用在這裡） |
|---|---|
| 迴旋 | 折返之後的子彈 |
| 環繞 | 放出的那一波 |
| 佈雷 | 衝出去的地雷 |
| 加速 | 速度到 1.5 倍之後的子彈 |
| 牆反彈 | 第一次反彈之後的子彈 |
| 反向 | 往後射的那一份 |
| 蓄力 | 蓄滿的那一發 |
| 黏著 | 爆炸：倍增加在爆炸上；分裂 = 爆炸時噴出 3 發碎片；巨彈 = 爆炸波及周圍（50%）；穿甲 = 黏住前多穿 2 隻（多留 2 份） |
| 感染 | 爆出來的子彈 |
| 吸引 | 拉力：只有巨彈有效果（範圍 ×1.5）；其他組件只升級 |
| 攔截 | 回射的子彈 |
| 衝刺射擊 | 衝刺那一槍 |
| 架設 | 滿層時射出的子彈 |

| 組件 | 效果 |
|---|---|
| 分裂模組 | 每發拆成 3 發扇形，每發 ×0.4 |
| 巨彈 | 每發傷害 +30%，體積 ×1.8、擊退變強 |
| 穿甲塗層 | 穿透 +2 |
| 威力倍增器 | 傷害 +100% |
| 超頻模組 | 射速 ×2，連續射擊 3 秒後過熱、停火 1.5 秒；**熱度越高越痛**：傷害 +（熱度 × 40%）。**只能插在武器上** |
| 收束透鏡 | 子彈越少越痛：武器每次射出（含鏡像、分裂）只有 1 發時傷害 +60%，每多 1 發少 15%，5 發以上沒有加成（不管插在第幾個插座都最後算）。**只能插在武器上** |
| 鏡像迴路 | 再來一次：插在武器（或觸發器）上 = 武器多射一次（回響多一份）；插在玩法晶片上 = 它的產物多一份（迴旋折返多一發、環繞放出的那一波多一份、黏著爆炸兩次…）；兩個鏡像 = 3 份。吸引不能插 |
| 爆裂彈頭 | 命中時爆炸（半徑 60，子彈傷害的 50%） |
| 燃燒彈頭 | 命中附加燃燒 3 秒，每秒是這一下傷害的 30% |
| 冰凍塗層 | 命中的敵人減速 40%，持續 2 秒（跟其他減速相乘：剩下的速度相乘，兩個 40% = 64%） |
| 電擊線圈 | 命中時 1 道電弧打附近另一隻（50%；附近沒有就打回目標 25%） |
| 破甲彈頭 | 命中的敵人 3 秒內受到的所有傷害 +25%（紅色準星）；跟感測器 4 層的弱點標記相加，沒有上限 |

**元素組件**（爆裂、燃燒、冰凍、電擊、破甲）：爆裂 = 命中爆炸 50%（半徑 60）、電擊 = 1 道電弧、冰凍 = 減速 40%，兩個同樣的相加。插在黏著上 = 爆炸時帶這些效果（爆裂再炸一圈）。盾衛照樣擋不住爆炸、電弧、燃燒。

同一個晶片上的組件，**插在哪個插座、誰先誰後結果都一樣**（例：一次射 4 顆的武器［巨彈、分裂］和［分裂、巨彈］都是 12 發大彈）。

- **傷害加成分兩種**：武器加成 = 武器（或觸發器）插座上的倍增、巨彈 +30%，加上蓄力、速度倍率、衝刺射擊，全部相加；晶片加成 = 插在玩法晶片上的倍增、巨彈，作用在同一下命中的全部相加。最終 = 基礎 ×（1 ＋ 武器加成）×（1 ＋ 晶片加成）。

### 觸發器（放在電路格，不會升級）

觸發時用武器再射一次**回響**（傷害 50%），**右邊的晶片只作用在回響上**（開火時不執行），最多巢狀 3 層（每多一層回響傷害再減半：50% → 25% → 12.5%）。觸發器也有插座：插在上面的組件作用在回響上。環繞、蓄力、衝刺射擊不能放在觸發器右邊（變灰）。

| 觸發器 | 什麼時候觸發 |
|---|---|
| 命中觸發器 | 子彈命中敵人時，從命中點沿子彈原本的方向射（可以打到被命中的這一隻） |
| 消失觸發器 | 子彈消失時，從消失的位置沿子彈原本的方向射：飛完射程、穿甲用完、撞到大地圖的牆（回響往反彈的方向射）、黏著引爆、地雷時間到、迴旋飛回飛船都算；被盾反彈、被地圖物件擋住、飛出場地不算 |
| 定時觸發器 | 子彈飛行中每 0.3 秒往左右兩側各射一次，每顆子彈最多 5 次（10 發）；停住的地雷不算 |

航圖節點「奇異點」可以投入晶片強化電路格（見「航圖與獎勵」）。

### 零件
每層小好處＋小代價，同種疊到 2 層、4 層開啟特性。**疊法**：同一項屬性「增加」的百分比全部相加（散熱片 4 層射速 +24%，再加疾風 +20%、急冷 +30% = +74%），「減少」的各自相乘（重裝甲 2 層移動速度 0.96² = −8%，疊再多也不會變成 0）。零件格有限（6 格，擊沉旗艦時可以選零件格 +1），要專心疊一種還是分散開好幾種，是主要的取捨。

**零件換電路格**：開局電路只有 2 格晶片，每裝 2 層零件（任何種類都算），電路 +1 格（最多 8 格）。拿到好晶片卻沒有格子放時，可以改拿零件把格子換出來。

| 零件 | 每層 | 2 層 | 4 層 |
|---|---|---|---|
| 重裝甲 | HP +20｜速度 −4% | 厚甲：單次受傷最多扣 20% 最大 HP | 衝撞：撞到敵人造成「最大 HP × 45%」並撞飛，自己不受碰撞傷害 |
| 輕裝甲 | 衝刺冷卻 −8%｜受到的傷害 +3% | 偏折：被打到後無敵時間 +0.8 秒 | 無傷連殺：沒被打中時每擊殺 1 隻傷害 +3%（最多 15 層）；被打中歸零（護盾擋下不算） |
| 加速器 | 速度 +6%｜HP −10 | 疾風：移動中射速 +20% | 突擊：衝刺穿過的敵人受「武器傷害 × 4」 |
| 散熱片 | 能量容量 +2｜受傷 +4% | 急冷：衝刺後 2 秒射速 +30% | 排熱爆發：衝刺時朝四周放出 12 發 |
| 感測器 | 子彈速度 +8%｜衝刺冷卻 +5% | 鎖定：打中敵人後 1 秒內子彈追蹤那一隻（第一發要自己打中） | 弱點標記：被打中的敵人 3 秒內受傷 +25%；看得到小行星後面的敵人 |

**均衡**：5 種零件都至少 1 層時，每層的好處 +30%。外觀會跟著零件變（裝甲變厚、尾焰變長、散熱鰭、天線）。

## 解鎖（局外成長）

玩越多，能選的飛船、武器、晶片越多；不會變強，只是選項變多。基地的停機坪、軍械庫、晶片庫看每一樣的條件和進度（跨局累計，存在這台裝置的瀏覽器）。沒解鎖的飛船不能出發、武器不能選；沒解鎖的晶片不會出現在三選一、補給站、黑市、？事件、開局晶片。

- 飛船、武器照打到哪裡：打倒第 1 星區旗艦 → 幻影號、到達第 2 星區 → 軌道砲、打倒第 2 星區旗艦 → 星門號、到達第 3 星區 → 相位刃、通關第一章 → 哨兵號。
- 晶片照玩相關的晶片（玩法擊殺累計 100 次）或累計的事（完成幾局、打倒精英、擊殺數、回響擊殺）；攔截跟相位刃一起在到達第 3 星區時解鎖（相位刃要裝攔截才會格擋）。完整清單看基地的軍械庫、晶片庫和停機坪。
- 進度從 2.20.0 開始算：2.20.0 以前的遊玩紀錄已刪除，章節進度只照 2.20.0 以後通關（或打到無盡模式）的紀錄。
- 之後加了新的解鎖條件，第一次開啟時會用遊玩紀錄（最近 50 局）補上新條件的進度。
- 一局結束時，新達成的條件會顯示在結算畫面（通關後直接回基地的，顯示在基地）。
- 沙盒、靶場一律全開。

- **寶藏無人機**（20%，隨機一區）：出場橫幅「✦ 寶藏無人機」，金色光暈。HP 156（照難度倍率），不攻擊、撞到也不扣血、不掉晶體；往離最近玩家的反方向逃（速度 230，飛船 270；離你 450 外慢下來），會左右閃，被逼到牆角就跑不掉。**15 秒內打掉：這場的三選一保證一格稀有晶片**；最後 3 秒光暈變藍、船身快閃，時間到就躍遷離開。

三選一上會寫這場拿到幾格保證（刷新也保證；多人時每個人都保證）。

一波的敵人預算 ＝（5 ＋ 波次 × 3 ＋ 難度 × 3）× 1.4（1 預算 ≈ 1 隻蟲群）。一般戰在第 1 星區前 3 層打 2 波，之後都是 3 波，所以新星區開頭的敵人不會比上一個星區結尾少。

**大地圖與區域**：一般戰、精英戰是一張不規則的大地圖，分成 2～3 個區域（一區一波）。每個區域由幾個大圓疊成（L 形、花生形、Y 形…），空地大約是方形場地的 2/3，邊緣坑坑窪窪；區域之間用短通道相連，通道中間有**閘門**。右上角有小地圖（整張地圖、閘門、敵人、飛船）。

- **牆**：擋住飛船、敵人和雙方的子彈。牆反彈的子彈照牆面的角度彈開（入射角 = 反射角）；其他子彈打到牆就消失（過載砲在牆上爆炸）；敵人的子彈也一樣，牆可以當掩護。環繞中的子彈、迴旋的回程、停住的地雷不受牆影響。敵人會繞牆追過來。
- **閘門**：這一區清完才打開（不在畫面裡時飛船旁邊有箭頭，照繞牆的路線指過去），地上的晶體全部吸過來。有人穿過閘門就開始下一區；穿過去之後不能回頭，敵人和子彈一律穿不過閘門（子彈打到閘門跟打到牆一樣）。多人：一個人穿過去就開始，另一個人之後自己飛過去加入；倒下的人會被搬到新區域的入口，隊友才救得到。
- 敵人散在這一波的區域各處出生（離你至少 500，可能在牆後、在側邊），不會一起生在面前。最後一區清完就結束戰鬥。沙盒、靶場是方形場地。
- **警戒**：敵人出場後先待機，在出生點附近慢慢晃（70 內），不追、不開火。你靠近到 450 內、或打到牠（子彈、爆炸、電弧都算，打在盾衛的盾上被彈開也算），牠才發現你（頭上跳出紅色「!」），並叫醒身邊 250 內還在待機的同伴（被叫醒的不會再往外叫），所以敵人會一群一群過來，不會整區一起湧上。母巢待機時照樣生蟲群，生出來的在母巢旁邊晃，母巢醒了一起醒。不待機的：亂入的精英、寶藏無人機；旗艦戰、沙盒、靶場也不待機。
- **警報艇**：第 2 區以後每一區 30% 機率有一艘（蟲潮那一區沒有），紅色警示燈慢慢轉。不攻擊、撞到不扣血，平常在出生點附近晃。**被打到開始響**（燈轉很快、紅光大閃），往遠離你的方向逃（速度 170，飛船 270）；1.5 秒後開始每 0.5 秒叫醒身邊 400 內待機的敵人（紅色脈衝圈，第一次有橫幅「⚠ 警報」），邊逃邊叫，一直響到被打掉。1.5 秒內打掉就完全不會叫。HP 54（照難度倍率），掉 3 顆晶體。
- **王關場地**：旗艦戰也是用同一套方法產生，只有一區、沒有閘門，大小跟方形場地差不多，形狀照王：星噬母艦是圓形大廳＋外圍 5 個小凹室；裂界獵艦是細長的菱形（衝鋒有距離，撞到牆就停）；終焉核心是圓形場地，中間四根柱子排成十字（可以擋彈幕）；雙子獵艦跟星噬母艦一樣是圓形大廳＋凹室；星環守門者是空曠的大圓（核心在正中間）。王的子彈打到牆、柱子也會消失；王被牆擋住時會橫移找角度。
- **雙子獵艦**：HP 3000，兩艘共用一條血（打哪艘、燒哪艘都扣同一條）。兩艘繞著同一個中心轉（半徑 230、每秒 0.65 弧度，暴走 1），中心每秒往最近的玩家飄 45。兩艘都在隊形上時中間連著光束（寬 14，碰到受 24 傷害）；一艘衝鋒時光束斷掉。出招：輪流一艘衝鋒（預警線、往兩側灑彈）、兩艘一起扇形齊射、兩艘一起狙擊、兩艘各部署噴吐者。子彈傷害 ×1.6。
- **星環守門者**：HP 3200，待在場地正中間不動。光束停 2 秒（最後 0.9 秒先畫細的預警線）→ 開 5 秒：2 條（暴走 3 條）從核心射到牆，跟著核心轉（每秒 0.38 弧度，暴走 0.55），寬 16、碰到受 24 傷害。核心每 4 秒（暴走 3）放一圈 20 發。身邊 4 座砲塔（各 HP 450，跟著核心轉、不吃擊退）各管一招，打掉那招就沒了：瞄準砲塔（每 1.8 秒朝你三連發）、環形砲塔（每 3 秒一圈 16 發）、轟炸砲塔（每 3.4 秒 2 個落點紅圈）、召喚砲塔（每 6 秒 3 隻蟲群，場上最多 8 隻）；暴走時砲塔出招間隔 ×0.7。
- **終焉核心的落點轟炸**：在最近的玩家身邊標 4 個紅圈（半徑 110，其中一個在腳下；暴走後 6 個），1.2 秒後爆炸，圈裡的飛船受 25 傷害，躲在柱子後面也會被炸。

## 地圖物件

大地圖的每個區域各自抽：一半機率沒有地圖物件；有的話一般戰 1～2 種、精英戰 1 種（行星或彗星）。開場一次放好：行星、黑洞放在空地（行星周圍留得出飛船過得去的寬度，黑洞核心離牆至少 200、離入口至少 420），都不擋閘門；小行星帶從一邊的牆拉到另一邊的牆（挑比較窄的地方），一樣留 2 個縫；彗星只在你所在的區域出現，從那一區的牆邊飛進來。旗艦戰沒有地圖物件（王關場地本身就有凹室、柱子這些地形）。靶場沒有。

敵人看不到你（中間隔著行星或小行星）時會照路線繞過去，或從小行星帶的縫鑽過來。旗艦被擋住時會橫移找角度，瞄準型攻擊（扇形、狙擊、彈牆）最多等 1.5 秒再打。

| 小行星帶 | 擋住雙方的子彈和敵人（中間留 2 個寬約 80 的縫，敵人會鑽縫或繞過去；比飛船窄的縫飛船鑽不過去，衝刺也一樣）；旗艦的子彈、旗艦和滾動的刺殼撞上去會打碎（不掉晶體）。**被擋住的敵人看不到**：小行星後面有一塊灰霧（死角），霧裡的敵人只在小行星邊緣顯示「？」，感測器 4 層看得到）。只有單發 ≥ 30 的子彈或爆炸打得動，打爆掉晶體（耐久每 32 一顆，大約 2～4 顆） |

## 👥 多人連線

### 開房與開始
1. 一人按「開房間」，拿到 4 碼房號（房間列的「📋 複製」可以直接複製）；其他人輸入房號按「加入房間」（最多 4 人，含房主）。
2. 進房間就是**共用的基地**：每個人的飛船都在同一個基地裡（頭上有號碼，✓ = 準備好了，📖 = 在看面板），上方的房間列寫房號、章節、每個人準備好了沒。房主一個人也可以先進基地等。
3. 各自在停機坪選飛船、武器架選武器，到發射台按 E 準備（起始晶片三選一）；房主在發射台選章（所有人都解鎖的章才能選）。準備好了就不能換船、換武器；房間裡終端機不能用。全員準備好：所有人一起播出發動畫（在跑道上左右錯開，每個人的畫面都看得到其他人的船一起衝出去），播完開始。
4. 全員準備好就開始遠征。每局結束後大家回到同一個房間（共用的基地），回到房間、再準備一次就能開下一局。

1P ＝房主，2P～4P ＝照加入順序的隊友。**每個號碼一個顏色**（1P 青、2P 粉、3P 金、4P 綠）：船上方的號碼標籤、船底下的光暈、隊友血條、小地圖的點、航圖的投票標記、傷害結算都用這個顏色，大家選同一艘船也分得出來。

### 航圖與投票
- 星圖由房主產生，大家看到的完全一樣。
- 點節點就是投票（節點上會標 1P～4P，可以改投）。
- 大家都回到航圖後倒數 **20 秒**；大家都投了就不用等滿 20 秒。
- 選的節點不同時，**照票數比例抽籤**（兩人各投一個就是各 50%），畫面會顯示每個人投了什麼和抽籤結果。時間到還沒投的人不算票；都沒投就隨機。
- 有人選好、自己還沒選時，畫面最上面會出現提醒（開著電路編輯器、在商店也看得到）。
- 大家都選好（或時間到）後**倒數 3 秒**才進關卡。

### 錢包
- **每人一個錢包**，商店、補血、電路擴充、換零件都花自己的錢。
- **怪物掉落的晶體每人都拿**：不管誰撿到，每個人都 +1。戰鬥結束時地上沒吸完的也一樣。
- 精英 +15、旗艦 +50：每人各自拿。
- 跳過獎勵 +10、回收晶片、軍械台補償：只進自己的錢包。

### 獎勵與節點
- 戰鬥、精英、改裝廠、軍械台的獎勵，每人各自選。
- 商店、黑洞、維修站、改裝廠、軍械台各自進行（商店商品每人各自隨機）。
- ？事件：大家看到同一種事件（產生航圖時就決定），各自選、各自賭；扣血、晶體、三選一、終焉護殼都是自己的。下一場變難（求救訊號、星圖情報被發現）和寶藏星域是全隊的：誰觸發都算，敵人照最多的那個；打贏的獎勵照自己選的，自己沒選就照隊友的。隊友的終焉護殼由房主判定。
- 打贏旗艦：每人各自選「電路插槽 +1」或「零件格 +1」（房主要等隊友都選好）；由房主決定前往下一星區或結束遠征。

### 戰鬥
- 敵人數量 ×2 → ×2.5、敵人血量 ×1 → ×1.3，照難度從第 1 星區開頭漲到第 3 星區最後（兩個人的配裝一起疊，後期成長比單人快；無盡模式停在 ×2.5／×1.3）。三、四人：在線的人每多一個，敵人數量的倍數再 +0.6（三人 ×2.6 → ×3.1、四人 ×3.2 → ×3.7），血量跟雙人一樣。隊友離線、房主一個人繼續時恢復成單人血量。
- 戰鬥中任何一人按 **Tab**，全員一起暫停；另一人畫面顯示「隊友正在編輯電路」，也可以同時整理自己的電路。
- 被擊墜：倒下的飛船留在原地，周圍有救援圈。活著的隊友待在圈內（半徑 70）累積 2 秒就能救起來，救的人分出自己當前一半的血量給對方，救起後無敵 1.5 秒；離開圈子進度會慢慢退回。沒被救起的人在戰鬥結束後以 30% HP 歸隊。全員都被擊墜才結束。
- 任何一人切到其他視窗或分頁，全員一起暫停（瀏覽器會停住背景分頁的遊戲）。
- 星門號的傳送門大家都能用：隊友被包圍時，可以從你的門撤出來。
- 小行星擋視野各算各的：你看不到的，隊友可能看得到。

### 斷線與重新連線
- **怎樣算斷線**：連線中斷、對方關掉或離開（馬上知道），或超過 5 秒沒收到對方任何訊息（關掉瀏覽器、當機、網路斷掉）；對方切到其他視窗時放寬到 70 秒。在看結算時有人離開不算，各自看完各自回房間。
- **隊友斷線**：房主那邊暫停（其他隊友也一起暫停），房間保留 **120 秒**。房主可以選：
  - 等隊友回來；
  - **自己繼續玩**：隊友從場上移除，房間一直開著，隊友隨時用同一個房號回來就接上當下的進度；
  - 結束這一局（存下紀錄）。
- **隊友那邊**：自動重試一次，也可以按「重新連線」。就算重新整理了頁面，選「多人連線」後輸入同一個房號也能回到這一局：電路、倉庫、插座數、奇異點強化的格子、零件、玩法擊殺、錢包、血量、傷害統計都會從房主那邊還原，戰鬥中斷線會回到同一波。重新整理過的分頁會記得自己是幾號，兩人同時斷線也會各自坐回原本的位置。
- **房主斷線或重新整理**：這一局無法恢復（整局遊戲在房主的電腦上跑）。

### 畫面資訊
- 右上角「連線延遲」：兩台電腦之間來回一趟的時間（綠 < 80ms、黃 < 150ms、紅）。房主自己的操作沒有延遲，房主畫面上的隊友大約晚這個數字的一半。
- 左上角：自己的 HP、衝刺冷卻、蓄力／超頻熱度與傷害加成／架設層數（有裝時）、錢包、護盾層數，以及隊友的血條。
- 結算畫面：「多人傷害結算」（每個人的傷害、占比、擊殺、最高單發）＋自己的傷害明細。每一擊都記在打出的人身上，擊殺算在補最後一刀的人身上。

## 🎯 靶場

用來確認晶片機制。電路一開始有 6 格空位，按 Tab 從晶片庫放晶片；「🚀 機體」分頁可以換飛船、武器、武器升級，直接加減零件層數。關掉編輯器時數據自動歸零，方便比較不同電路。

- 標靶打不死、不會動、不會攻擊，被擊退後會彈回原位。
- **1～4**：換標靶排列（單一／一排 8 個：看穿透／密集 19 個：看爆炸、分裂／散開 10 個：看追蹤、電弧）
- **6 爆量**：換成一組子彈很多的散彈配裝（迴旋、環繞、攔截 Lv3…＋蟲群核心），10 個標靶圍在四周，每 1.5 秒一圈 32 發環形彈射向飛船（不扣血）
- **5**：實戰：清掉標靶，改成一波波真的敵人，無限波次、越來越強（每 5 波精英、每 10 波旗艦）；飛船不會死（血量歸零時回滿）。按 1～4 回到標靶。數據面板照樣計算。
- **T**：慢動作 ×0.25　**R**：清除數據
- **生成敵人**（按鈕列第二排）：選敵人種類（全部敵人和三隻王）和難度（1／3／6／10／17，血量照那個難度），切換「不動／會動」（不動 = 跟標靶一樣不移動、不攻擊）和「打得死／打不死」；按 **G** 生在滑鼠指的位置（**Shift＋G** 一次 5 隻），按鈕列的「G 生成」生在飛船前方 300（手機用）；**C** 只清掉手動生的敵人；換標靶排列（1～4）時也會清掉。
- 右上角：實測 DPS（近 3 秒）與估算 DPS 對照、總傷害、命中次數、最高單發、傷害來源拆分、每發幾顆、每一層觸發展開幾顆。
- 畫面上方有按鈕列（1～5、R、T、生成敵人），滑鼠或觸控也可以切換。

### 畫面提示
- **命中數字的顏色**照倍數（這發傷害 ÷ 武器基礎傷害，例如雷射 8）：1 倍以下灰、1～2 倍白、2～4 倍黃、4 倍以上紅色大字。黏著爆炸（綠）、燃燒（黃）、彗星（淡藍）照舊。
- **粉紅外圈**：帶觸發器的子彈（觸發時才執行觸發器右邊的晶片）。
- **敵人身上的粉紅小點**：黏著的子彈數。**紅色準星**：弱點標記中。
- 例：「相位刃 → 命中觸發器［分裂］」＝開火 2 片刃（帶觸發）；命中時用 50% 傷害再射一次，那一次才分裂成 6 片（分裂插在觸發器上 = 作用在回響）。

## 遊玩紀錄

基地「🏆 戰績」門裡的「📜 所有遊玩紀錄」。只存在這台裝置的瀏覽器裡（最近 50 筆），可以單筆或全部複製成文字，也可以「🗑 刪除所有紀錄」（畫面上會再確認一次）。V2 的紀錄和 V1 分開存。

每筆紀錄有 `mech`：零件層數、零件格、開啟的特性、各晶片的玩法擊殺數（`playKills`）。

「📋 複製這局紀錄」「📋 複製這筆」複製的是**精簡文字**（約 700 字，沒有 JSON 符號，貼到聊天軟體不會被轉成表情）；「複製全部紀錄」是完整 JSON（備份用）。

### 遊玩紀錄的代號

| 類別 | 代號 |
|---|---|
| 結果 | 死、通（通關）、退（中途結束）、斷線、進行中 |
| 節點 | 戰、精、王、改（改裝廠）、軍（軍械台）、修（維修站）、補（補給站）、洞（黑洞） |
| 敵人 | 蟲（蟲群）、刺（刺殼）、噴（噴吐者）、獵（虛空獵手）、砲（砲艦）、拖（拖曳艦）、隊（三艦編隊）、艇（彈幕艇）、列（列隊蟲）、盾（盾衛）、分（分裂體）、碎（碎裂體）、潛（潛伏者）、巢（母巢）、母（星噬母艦）、裂（裂界獵艦）、核（終焉核心）、雙（雙子獵艦）、門（星環守門者）、瞄／環／轟／召（守門者的砲塔）、彗（彗星）、洞（黑洞核心） |
| 被打 | 敵人代號＋「彈」（子彈）或「撞」（撞擊），例如「噴彈」「核撞」 |
| 晶片 | 遊戲裡的短名，後面的數字是等級（「超頻2」）；進化後照進化的名字 |
| 零件 | 名稱前兩字＋層數（「散熱2」） |
| 節點紀錄 | 「戰28-10」＝ 戰鬥 28 秒、掉 10 血；「+」是回血 |
| 取得 | 「2-3佈雷2 伏擊網 插槽」：同一層拿到的東西只在第一個前面寫層號 |

傷害數字都是完整數字，不簡寫。

晶片傷害的歸屬：
- 反向只算多射出來的子彈；分裂只算分出來的子彈（中間那顆還是原本的來源，例如插在觸發器上就算觸發器）。
- 黏著、佈雷、迴旋的回程、環繞放出／加速的速度倍率這些命中後才發生的加成，記在各自的晶片上。
- 伏擊網的電弧、感染爆出的子彈、攔截回射、衝刺射擊那一槍，基礎傷害也算在各自的晶片上。

多人局在這些情況自動存一筆：全員都被擊墜、結束遠征、戰鬥中斷線、中途離開。多人紀錄另外有：
- `coop.role`：房主／隊友；`coop.mate`：隊友的配裝（三人以上每人一段，前面標號碼）
- `coop.ping`：延遲平均、最低、90% 以內、最高、量測次數
- `coop.sync.maxGapMs`：同步訊息最長間隔（暫停中不算）。數字很大代表那段時間對方的遊戲停住了（例如切到背景）
- `coop.team`：每個人的傷害、擊殺、最高單發
